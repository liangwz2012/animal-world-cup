# 乡村足球赛 3D（claude5）

把《乡村足球赛》从 2D 升级为 3D 的独立工程，首发平台是**微信小游戏**，**横屏**。
美术方向是**动画片风格**：约 5.6 头身、圆润体块、大眼睛，卡通阶梯着色 + 反向外壳描边，
场景是**现代村镇主场**——维护草坪、窄红跑道、小型有顶看台和实用灯杆嵌在村庄里，
周围是二三层白墙小楼、屋顶太阳能热水器、稻田菜地、河流、梯田与村镇小集市；
既不是破败泥巴场，也不是城市职业大球场。

三件事是这一版的立项理由：

1. **人像村超**——球员不是标准运动员模板，而是屠户、骑手、返乡大学生、村医、女足尖子；
   身高体型、肚子、肩宽、晒痕、白发、护膝各不相同，球衣背后印号码和村寨名。
2. **地名是真的**——省 / 区县 / 乡镇三级全部来自公开行政区划快照（31 省、2709 个区县、
   12336 条乡镇地名），队名就是「乡镇名 + 村队」，场边横幅写着「××县××　欢迎八方乡亲」。
3. **球场有地方味**——9 个地域母版（西南山地村寨、江南水乡、岭南、北方平原、东北黑土、
   西北黄土绿洲、高原石村、海岛沿海、京畿近郊）叠加 34 个省级特色小品：鼓楼、风雨桥、
   吊脚楼、梯田、窑洞、葡萄架、蒙古包、四合院影壁、渔船晒网、椰林、白桦、麦垛、拖拉机……

## 现在能玩到什么

- 5 人制 / 7 人制两种赛制，上下半场、中场休息、全场结算；
- 七个操作键：**传**（长按直塞）、**中**（传中/挑传）、**射**（长按蓄力）、
  **抢**（长按滑铲）、**冲**（冲刺）、**换**（换人）、**技**（急停变向 / 踩单车）；
- 完整判罚：界外球、球门球、角球、任意球、点球、犯规、门将抱球与手抛球；
- 体力系统：老队长跑三趟就喘，冲刺掉体力，体力低了传球会飘；
- 天气时段：晴 / 黄昏 / 夜灯 / 雨后泥地 / 山风，雨后泥地球滚得更黏、人更容易打滑；
- **村寨杯**四轮晋级：乡邻杯 → 乡镇赛 → 县域争霸 → 州府决赛，对手全部是真实地名的邻村；
- 换个村：从 31 个省、2709 个区县、上万条乡镇里挑自己老家当主场。

## 美术方向（动画片风格）

- **比例**：头高约为身高的 1/5.6（写实是 1/7.4），四肢短一档且更粗，手是厚实的"连指手套"，肩是球不是方块；
- **脸**：大眼白 + 大虹膜 + 两点高光，粗眉毛，圆鼻头，上扬的嘴角，腮红；
- **着色**：`MeshToonMaterial` + 三阶灰阶渐变，光影切成干净色块，不是连续渐变；
- **描边**：反向外壳——同一副骨架再画一遍、沿法线外扩、只画背面，所以描边会跟着骨头动；
- **布光**：暖主光 + 天地反弹光 + 冷轮廓光；
- **影子**：径向渐变的软接触阴影，不是硬边圆片。

## 场景方向（现代村镇主场 B 版）

- 主场是维护良好的条纹草坪，只有门前和中圈有克制踩踏色；
- 草坪外是一圈窄红跑道、一座小型有顶主看台、两段开放台阶和四根实用灯杆；
- 观众贴近边线，小集市、农产品摊棚与农用三轮形成“全镇来看球”的生活气；
- 背景疏密布置二三层村居、公共服务建筑、太阳能热水器和路灯，不围成城市街墙；
- 农田、灌渠、河流、梯田、常绿树组和喀斯特山体占据更大背景比例；
- 地域小品退到外圈点缀，不使用破败村落、泥巴主场或职业大体育场表达乡村。

## 技术选择

| 项目 | 决定 | 原因 |
| --- | --- | --- |
| 渲染 | three.js 0.185 | 微信小游戏可用的成熟 WebGL 方案，主包压缩后仅 1 MiB |
| 人物 | 程序化蒙皮 | 21 根骨骼 + 一体化网格，1 人 = 1 drawcall，不依赖任何模型文件 |
| 动作 | 程序化动画 | 不用动捕/商业动作包，没有许可风险，步频由速度反推所以脚不打滑 |
| 贴图 | 运行时 Canvas 生成 | 包里 **零张图片**，球衣号码、脸、草皮、观众、横幅全是现画的 |
| 比赛规则 | 纯 JS 30 Hz | 与渲染完全解耦，同 seed 逐帧可复现，可回放可联机 |

## 目录

```
src/core/      比赛核心（确定性 30 Hz：物理、球员、AI、规则）
src/content/   内容层（真实地名、村民生成、地域文化、村寨杯）
src/art/       程序化美术（骨架、蒙皮、动作、贴图、球场、地域小品）
src/render/    three.js 世界（场景、光照、机位、插值）
src/ui/        UI 层（正交贴图层、菜单、HUD 与触控）
src/platform/  平台适配（微信垫片 / 浏览器）
tools/         构建、发布闸门、地名同步、本地预览
tests/         比赛核心、内容、动作的自动化测试
```

## 常用命令

构建 web 与微信两个产物：

```bash
npm run build
```

跑全部自动化测试：

```bash
npm test
```

发布闸门（包体、禁用 API、资源构成、合规词）：

```bash
npm run verify
```

本地预览（浏览器里验收观感和手感）：

```bash
npm run serve
```

预览地址支持强制画布尺寸，方便按机型截图（横屏机型宽在前）：`http://localhost:5177/?w=830&h=420`。
另有人物检查台，可单独看身材、动作和背号：
`http://localhost:5177/inspect.html?pose=shoot&back=1&count=3&dist=4`。

重新从行政区划快照生成地名表（需要 2D 版目录在旁边）：

```bash
npm run build -- --target=web && node tools/sync-places.mjs
```

## 微信小游戏

`dist/wechat` 就是可以直接用微信开发者工具打开的工程（`game.js` / `game.json` /
`project.config.json`）。当前主包 **1.02 MiB**，远低于 4 MiB 硬上限，包内没有任何图片
或音频文件。真机跑起来后控制台会有 `GameGlobal.__RURAL3D_BOOTED === true`。

**尚未完成的事**（不要当成已经能上架）：

- 没有在 iOS / Android 真机上跑过，帧率、内存、长局稳定性未验收；
- 没有接入登录、排行、分享、广告与任何后端服务；
- 没有音效（这一版刻意不带任何音频文件）；
- 没有填写著作权人、出版物号、备案号等提审必需的资质信息；
- 没有做防沉迷相关的自建界面（正式 AppID 由平台统一展示）。
