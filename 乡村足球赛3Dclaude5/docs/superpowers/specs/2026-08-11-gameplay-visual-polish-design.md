# 乡村足球赛 3D 主比赛画面精修设计

日期：2026-08-11

目标项目：`/乡村足球赛3Dclaude5`

里程碑：V1 现代槕江村超黄昏主场视觉标杆

## 1. 目标

在不修改比赛规则、确定性核心和微信发行约束的前提下，把当前“功能完整但程序化痕迹明显”的横屏比赛画面，提升为现代、热闹、组织成熟的县城群众足球盛会。画面保留黔东南山水、村队与地方文化身份，但不再用破旧村屋、泥巴场和原始木看台表达“乡村”。

首轮只做一个可验收的纵向切片：默认贵州槕江地域、5v5、黄昏、830×420 横屏主比赛镜头，外加三名球员的人物检查台。场馆参考现实槕江村超的绿茵、红跑道、满场看台、泛光灯、直播机位、县城楼群与河谷山景。该切片同时打通材质、几何、人物、光影、HUD、性能和版本保护，通过后再扩展九个地域。

### 1.1 现实参考基准

- [2025 年村超灾后重启现场（新华社）](https://www.news.cn/sports/20250727/91917625ca914862ae8398df76e6cac2/c.html)：当代县城体育场、新铺绿茵、高密度观众、泛光灯和城市/山水共同背景。
- [2025 年村超全国赛总结（新华社）](https://www.news.cn/sports/20250824/9a2de09aca3f490fb410d82e1dc0f52e/c.html)：全国性群众赛事、民俗展演与文旅人流融合。
- [2026 年贵州村超冠军赛新闻发布会](https://www.scio.gov.cn/xwfb/dfxwfb/gssfbh/gz_13849/202605/t20260514_989170.html)：省级赛事体系与现代组织规模。

上述资料只用于确认场馆类型、城市关系、观众密度和活动氛围；不复制官方标志、赞助牌、现实球队名称或摄影作品构图。

## 2. 方案选择

采用“程序化材质 + 软边造型 + 电影光色 + 信息层级”的组合方案。

- 不采用角色优先单点重做：近景会改善，但主比赛远景仍显廉价。
- 不采用外部模型/高清图片重制：会破坏零图片、零模型与低包体架构。
- 生成式图像只可作为设计参考；最终效果必须翻译为 Canvas 绘制配方、顶点色和程序化几何，参考图不进入发行包。

## 3. 范围

### 3.1 包含

1. 主比赛画面的专业化草地、红跑道、四周看台、泛光灯、安全护栏、替补席、媒体/直播机位、志愿者通道和群众观赛区。
2. 环境材质库：维护良好的条纹草坪、塑胶跑道、水泥预制看台、涂装钢构、座椅/护栏、广告布、球衣布料和县城建筑立面。
3. 三名代表球员的脸、发型、身材轮廓、现代村队球衣织纹、汗渍/草渍和描边。
4. 黄昏主光、冷轮廓光、天空雾景、软接触影和低成本氛围效果。
5. HUD 的计分牌、操作键、球权提示和提示消息层级。
6. 修改前后对照截图、运行时资源预算和发布门禁。
7. 在实施开始时为当前未跟踪工程建立一份可恢复的基线版本，不带入 `node_modules`/构建产物，不夹带父仓库其他改动。

### 3.2 不包含

- 不修改 `src/core` 规则、AI、物理、判罚和数值。
- 不改全部九地域；本轮只证明黔东南模板。
- 不加入实时高分辨率阴影、PBR 扫描贴图、骨骼数增加或动捕。
- 不做音效、联机、排行、登录和提审。

## 4. 视觉设计

### 4.1 画面层级

画面按“球与控球球员 → 附近队友/对手 → 球场白线 → 红跑道与满场看台 → 县城楼群/河谷/山体”建立五层焦点。球员和球的亮度/冷暖对比高于草地；观众通过密度、色彩节奏和小幅动态表达热度；城市楼群与河岸灯光建立现代槕江身份；山体通过冷色、雾和对比递减退到远景。

### 4.2 程序化材质

每种材质使用相同的四层配方：基色大块、低频色差、结构纹理、局部磨损。随机数由地域/材质 seed 驱动，确保同村稳定复现。

- 草地：使用深浅相间的维护条纹、很轻的方向性草理和局部踩踏变色；不再把大面积黄土秃斑作为主视觉。
- 跑道/看台：塑胶跑道有克制颗粒和跑道线；水泥看台用预制分缝、台阶阴影和局部人流磨损建立层次。
- 钢构/设备：泛光灯塔、护栏、替补棚、直播平台使用统一涂装钢构语言，保持线条干净与现代。
- 建筑/城市：近景场馆建筑细节清晰，远景楼群用窗口光点、大色块与层级递减表达，避免每栋楼高细节建模。
- 布料：球衣、原创横幅与观众衣服分开织纹密度，只使用很弱的明暗噪点，不出现官方/现实赞助标识。

Canvas 纹理必须能无缝平铺；不把已烘进图片的固定阴影冒充为材质光照。

### 4.3 几何与造型

不通过大幅增加面数来变“精细”，而是建立现代场馆轮廓与人群密度：先完成草地、红跑道、看台、顶棚、泛光灯塔、替补席、护栏和直播位的整体剪影；观众使用分层广告牌/实例化低面数人群混合，近处有个体、远处有密度；县城楼群、河岸和山体使用三层简化轮廓建立景深。地方建筑与民俗元素退到入口、观众区和场间展演区点缀，不再把老村屋摆成球场主背景。

### 4.4 人物

保持 21 骨骼和现有动作曲线。精修优先级为：

1. 个体轮廓：头型、下颌、肩宽、肚子、手脚厚度。
2. 脸部层次：眼睑/鼻翼/嘴角/腮红使用软边形状，不增加写实毛孔。
3. 发型轮廓：发顶、鬓角、马尾/丸子头从平面颜色提升为少量程序化几何。
4. 球衣信息：保留号码和村名可读性，加现代领口、袖口、缝线、局部汗渍/草渍和很弱的布纹；不在比赛中携带职业道具。
5. 描边：由固定宽度改为距离/质量档自适应；比赛远景保持轮廓，检查台近景不出现过粗黑边。

### 4.5 光影、氛围与 HUD

- 保留卡通阶梯光照，重新校准暗部、中间调和高光，避免灰白、黑斑和胶皮感。
- 不启用全场实时阴影；继续使用接触影，根据球员高度/姿态调整软硬与尺寸。
- 黄昏使用暖金太阳、冷蓝轮廓光和刚亮起的泛光灯；青灰山体、河岸反光与楼群窗灯建立现代县城夜幕过渡。雾密度必须保证球门与边线仍清晰。
- 观众小幅摆动、手机光点、志愿者和媒体区局部动态采用低频/低数量效果；低质量档关闭。
- HUD 使用深靛灰半透明底、暖米色文字和节庆红/金少量强调；不用大块高饱和底色覆盖球场。

## 5. 实现边界

- `src/art/textures.js`：保留人物图集入口；环境纹理配方拆入独立模块，避免继续扩大单文件。
- `src/art/props.js`：只改程序化轮廓和细节，继续使用 `GeoBuilder` 合批。
- `src/art/stadium.js`：组装新材质、地景层次和质量档，不引入比赛状态逻辑。
- `src/art/humanoid.js` / `src/art/textures.js`：人物几何与图集各自维持单一职责。
- `src/render/world.js`：管理光照、描边、氛围和质量档；不改固定 30 Hz 模拟。
- `src/ui/hud.js`：只改视觉层级和触控命中区周边样式，不改按键语义。

数据流为：`culture + timeOfDay + quality + seed` → 材质主题/程序纹理 → 合批场景与人物材质 → 世界光色/HUD。材质生成失败时必须回退为现有纯色/基础 Canvas，不阻断开球。

## 6. 性能与发行门禁

1. 发行包继续禁止 `.png/.jpg/.webp/.mp3/.glb` 等图片、音频和模型文件。
2. 微信主包继续小于 4 MiB。
3. 不新增每球员独有的几何 drawcall；描边保留单独质量开关。
4. 新增场馆细节仍合批；观众必须使用近/中/远三档表现；相比实施前基线，主比赛稳态 drawcall 增幅不超过 20%。
5. 除现有高档草地外，不新增单张超过 1024×1024 的持久 Canvas 纹理；新增纹理总像素不超过基线的 25%。
6. 低档关闭观众摆动、手机光点、远景楼群窗灯和近景附加细节，但必须保留现代场馆剪影、满场观众密度和比赛信息。

## 7. 验收

### 7.1 视觉证据

- 830×420 黄昏主比赛固定镜头：实施前/后同帧对照。
- 人物检查台：`idle` 正面、`shoot` 侧面、背号背面，同时显示三种身材。
- 可读性：球、控球球员、主客队、球场白线和比分不能被环境遮盖。
- 风格：一眼辨认为“现代槕江村超”：县城绿茵场、红跑道、满场观众、泛光灯、城市/河谷/山体共同背景，不出现破败村落、泥巴主场和贫困化视觉暗示。

### 7.2 自动门禁

- `npm run build`
- `npm test`
- `npm run verify`
- 新增固定 seed 的材质可复现性、Canvas 尺寸预算和低档回退测试。
- 发布包资源扫描仍为零图片、零音频、零模型。

### 7.3 真实状态

本里程碑只能声称“本地 Web 视觉切片完成”。微信开发者工具、Android/iOS 帧率、内存、发热和长局稳定性没有真实证据前，不得宣称真机验收完成或可提审。

## 8. 停止条件

完成现代槕江村超黄昏主场纵向切片、三人检查台、性能/发布门禁、前后对照和 `docs/STATUS.md` 更新后停止。不自动继续扩展其他地域、夜场满看台版或玩法。
