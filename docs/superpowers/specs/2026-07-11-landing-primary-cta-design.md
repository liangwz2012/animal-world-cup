# 首页“立即开赛”主按钮强化设计

## 目标

保持当前首页的球队、阵型、主客场、AI 难度、比赛时长和三个操作入口全部不变，只强化玩家操控比赛的主入口。玩家进入页面后继续沿用现有默认球队与默认参数，可以不做任何设置直接点击主按钮开赛；高阶玩家仍可完整调整所有配置。

## 范围

- 不删除、不折叠、不重排球队与阵型选择。
- 不改变默认球队、默认难度、默认时长和比赛启动逻辑。
- 不改变“观看 AI 对战”和“局域网对战”的文案、功能和相对顺序。
- 只调整主按钮的文案、颜色、尺寸比例、阴影和按压反馈。

## 视觉设计

主按钮采用金黄到橙黄的轻微纵向渐变，与绿色页面背景和两个浅色次级按钮形成明显对比。文字使用深绿色，避免黄色背景上的白字对比不足。

- 中文文案：`立即开赛`
- 其他语言使用对应的“立即比赛 / Play Now”短行动文案，避免继续使用偏赛事术语的“开球”。
- 主按钮所在第三列宽度约为前两个按钮的 `1.35–1.4` 倍。
- 常规横屏按钮字体约 `18px`，纵向内边距约 `16px`，最小高度约 `54px`。
- 两个次级按钮维持当前尺寸和颜色。
- 使用橙棕色底边阴影形成可点击的立体感；悬停时轻微提亮并上移，按下时下沉并缩短底边阴影。
- 保留现有手柄图标，不新增闪烁、循环缩放或强制动效。

建议色值：

- 渐变顶部：`#ffe768`
- 渐变底部：`#ffb331`
- 文字：`#314518`
- 边框 / 底边阴影：`#d97924`

## 响应式行为

- 常规横屏继续使用一行三列，比例改为 `1fr 1fr 1.38fr`。
- 页面内模拟横屏或高度较小时，主按钮仍比次级按钮更宽、更高，但字号和内边距随现有紧凑规则同步减小，不能造成页面裁切。
- 不通过整体缩放动画吸引点击，避免干扰球队和阵型选择。

## 验收标准

1. 首次进入时，当前默认球队和参数仍然已选中，无需任何额外操作即可点击“立即开赛”。
2. “立即开赛”在颜色、宽度和高度上明显高于另外两个入口，但不遮挡设置区和底部水印。
3. 三个入口顺序仍为“观看 AI 对战 / 局域网对战 / 立即开赛”。
4. 点击后的 URL 参数、选队结果、阵型和比赛启动行为与修改前一致。
5. 常见桌面横屏、手机原生横屏和页面内模拟横屏均无溢出、裁切或文字换行。
6. 悬停、按下和键盘聚焦状态可见，按钮文字在黄色背景上清晰可读。

## 验证

- 运行现有构建检查，确保样式和多语言 JSON 无语法错误。
- 在至少一个常规桌面横屏尺寸和一个手机横屏尺寸检查首页截图。
- 分别用默认配置和手动修改配置启动比赛，确认两条路径行为一致。
