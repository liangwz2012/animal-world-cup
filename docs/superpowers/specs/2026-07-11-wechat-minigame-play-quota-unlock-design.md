# 微信小游戏免费局数与二选一解锁设计

## 目标

《动物足球赛》首次提供 2 局免费可操控比赛。免费局数用完后，玩家必须在“完整观看激励视频”和“转发邀请”之间任选一种；完成任意一种后增加 2 局。该门槛同时应用于首页“立即对战”和赛果页“再来一局”。观看 AI 对战不消耗局数。

## 已确认规则

- 新玩家初始可玩局数为 2。
- 每开始一场可操控比赛消耗 1 局，避免进入比赛后退出绕过计数。
- 完整观看一次激励视频增加 2 局。
- 发起一次转发并返回游戏增加 2 局。
- 转发界面停留达到 2 秒，返回后直接发放 2 局。
- 少于 2 秒返回时不自动发放，弹出“返回得有点快，是否已经完成转发？”。
- 快速返回确认框包含“已完成转发”和“重新转发”：前者发放 2 局，后者不发放并重新调起转发。
- 同一次广告或转发流程最多发放一次，重复回调、重复点击和多次 `onShow` 不得重复增加。

## 玩家流程

1. 玩家点击“立即对战”或赛果页“再来一局”。
2. 可玩局数大于 0 时立即扣除 1 局，并进入现有 Logo＋滚动足球加载页。
3. 可玩局数等于 0 时显示解锁面板，主标题为“本轮免费次数已用完”，并显示两个同级按钮：
   - “看广告 +2 局”
   - “转发邀请 +2 局”
4. 解锁成功后更新剩余局数，关闭面板，并由玩家再次点击“立即对战”开始比赛，避免广告/分享回调直接启动场景造成误触。
5. 解锁失败、取消或未完整观看时留在解锁面板，并提供清晰原因与重试入口。

## 组件边界

### PlayQuotaStore

只负责局数状态与持久化：读取、消费、奖励和防止负数。首版使用 `wx.getStorageSync`/`wx.setStorageSync`，存储键带版本号。接口保持异步兼容，后续可以替换为云端账户计数而不修改 UI 和比赛启动逻辑。

核心状态：

- `remaining`：当前可玩局数，首次默认为 2。
- `version`：存储结构版本。
- `updatedAt`：最后更新时间，供迁移和问题排查使用。

存储失败时仅在本次运行使用内存状态，并记录诊断信息；不得因为存储异常无限增加局数。

### UnlockService

只负责广告与转发解锁，不直接启动比赛。

- 激励视频：使用 `wx.createRewardedVideoAd`。仅 `onClose` 返回 `isEnded === true` 时奖励 2 局；中途关闭不奖励。
- 转发：调用 `wx.shareAppMessage` 后记录一次内存态分享会话，包括唯一 ID、开始时间、是否已结算和回调锁。
- 分享返回：监听 `wx.onShow`。分享会话未结算且已经离开分享流程时，计算停留时间。
- 分享会话不写入持久化；游戏被关闭或重启后不补发，防止旧会话误领奖励。

### QuotaGate

位于现有比赛启动入口之前，统一拦截首页“立即对战”和“再来一局”。观看模式绕过该门槛。它只返回“允许开始”或“需要解锁”，不负责绘制 UI。

### UnlockOverlay

使用当前 Pixi 矢量 UI 绘制，保持高 DPI 清晰度和现有绿色、米白、金色视觉语言。所有按钮沿用已经修复的 Canvas 实际显示区域触点换算，支持微信真机触摸和开发者工具鼠标。

## 转发时间判定

- 调用转发接口时记录 `startedAt` 并锁定转发按钮。
- 游戏重新 `onShow` 时计算 `elapsed = now - startedAt`。
- `elapsed >= 2000ms`：直接发放 2 局并将会话标记为已结算。
- `elapsed < 2000ms`：显示快速返回确认框，不发放局数。
- 点击“已完成转发”：发放 2 局并结算当前会话。
- 点击“重新转发”：取消当前会话并创建新会话，再次调起转发。
- `onShow`、按钮点击或底层回调同时到达时，通过会话 ID 和 `settled` 锁保证只发放一次。

微信转发接口无法可靠返回“用户已经发送成功”，因此 2 秒仅用于过滤明显的立即返回，不作为发送成功的技术证明。

## 广告配置和异常处理

- 广告位 ID 放在独立发布配置中，不硬编码进业务模块。
- 广告未配置、加载失败或展示失败时，在解锁面板显示“广告暂时不可用，请稍后重试或选择转发”，转发入口保持可用。
- 广告被中途关闭时提示“完整看完广告才能领取 2 局”。
- 广告对象复用，展示失败时尝试重新加载，但一次点击最多触发一次展示流程。
- 解锁过程中按钮进入加载/锁定状态，防止连续点击同时开启广告和转发。

## 比赛计数和退款

- 玩家确认开始可操控比赛时先预扣 1 局。
- 原版引擎成功进入比赛后将预扣标记为已消费。
- 如果引擎在进入比赛前明确启动失败，则退回本次预扣；普通加载等待不触发退款。
- 比赛中返回主页、主动退出或比赛结束均视为该局已经使用，不退款。
- “再来一局”必须重新经过相同门槛，不能绕过计数。

## 诊断与测试

诊断状态记录在 `__ANIMAL_FOOTBALL_QUOTA_DIAGNOSTICS__`，只包含剩余局数、最近一次动作、错误类型和时间，不记录好友或分享目标信息。

自动测试覆盖：

- 新玩家恰好获得 2 局。
- 两次开始后第三次被门槛拦截。
- 完整广告奖励 2 局，中途关闭不奖励。
- 分享返回达到 2 秒直接奖励。
- 分享返回不足 2 秒弹确认且不自动奖励。
- 快速返回确认领取、重新分享和重复 `onShow` 均不会重复发放。
- 首页开始与赛果页再来一局共用同一份计数。
- 观看 AI 对战不消耗局数。
- 存储异常、广告加载异常和引擎启动失败的行为符合上述兜底规则。
- 安卓、iOS 高 DPI 触点与开发者工具鼠标均可操作解锁面板。

## 不在本次范围

- 服务器强校验分享是否真实发送（微信客户端没有提供相应结果）。
- 付费购买局数。
- 每日重置、签到奖励或无限体力订阅。
- 多人对战的单独次数体系；后续多人模式默认复用 `QuotaGate`，再根据运营规则调整。
