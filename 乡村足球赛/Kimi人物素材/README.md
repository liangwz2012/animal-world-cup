# Kimi人物素材 · 村超全新 12 人预览包

本包是**未应用到游戏**的全新人物 + 服装预览素材，用于替代现有"偏商业卡通"的乡村队 12 人。确认效果后再走替换流程；现有运行素材未受任何影响。

## 目录结构

- `manifest.json`：12 人名单（id/姓名/年龄/职业/位置/号码/肤色/脸型/发型），位置号码与现有运行时名单一一对应。
- `players/<角色id>/`：每人 9 张运行规格 PNG（`portrait` 192×192、`head`/`head_back` 81×77、`neck` 20×18、`arm_left/right`、`hand_left/right`、`knee`）+ `source-sheet.webp`（768px 参考母版）+ `skin-source.json`。
- `preview/`：每人赛场联系表（头像/严格正面/严格背面）+ `roster-12.png` 运行像素阵容总览 + `roster-12-hd.png` 高清阵容总览（从 768px 母版裁切、去洋红底）。
- `球衣预览/村超球衣套件预览.png`：村超主题「经典撞色」三套成衣人形图高清版（主场大红+米白+稻金胸条/客场米白+红蓝/门将亮黄+藏青，真实切片轮廓，门将含手套）。
- `球衣预览/村超球衣全套件清单.png`：14 类部件逐件高清图（球衣正背面、双袖、短裤腰片、双裤腿、三只球袜、双球鞋、门将双手套）。
- `球衣套件(未应用)/{home,away,goalkeeper}/`：38 件原生尺寸运行规格套件 PNG，已校验尺寸与 RGBA，未来应用时直接可用。

## 生成方式

- 人物母版：真实生图模型（ChatGPT 图像生成，经 CDP 驱动本机 Chrome 克隆档案），洋红底三视图（胸像/严格正面/严格背面），提示词在 `.tmp/cdp/prompts/`。
- 切片：复用现有管线 `tools/process-rural-character-sheet.mjs`（新增 `--manifest` 参数；去底后新增洋红去溢色步骤，防止洋红残边）。
- 身体小部件（颈/臂/手/膝）：`tools/generate-rural-body-parts.mjs` 从各人头像自动采样肤色程序化生成。
- 球衣套件预览：`tools/render-cunchao-jersey-preview.mjs`（与运行时同坐标/光照逻辑），样式 id `cunchao-brocade`。
