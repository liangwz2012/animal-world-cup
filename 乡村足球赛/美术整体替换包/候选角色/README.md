## 统一技术约束

- 所有角色采用同一套比赛骨骼、身材比例、站位和球衣轮廓；每人拥有独立的人体分层，职业只体现在面孔、发型与细节气质，不穿职业制服上场。
- 头像目标尺寸：`192 × 192 px`。
- 运行时头部切片目标尺寸：`81 × 77 px`；球衣前/后片目标尺寸：`56 × 52 px`。
- 候选图不覆盖 `teams/*` 下任何现有文件；审美确认后再由固定尺寸处理流程输出可替换 PNG。
- 不包含真实人物肖像、行政机关标志、赛事标志、品牌标识或任何文字水印。
