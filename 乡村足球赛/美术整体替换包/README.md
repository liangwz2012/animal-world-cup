# 乡村足球赛：整体替换美术包

这里集中放置八支队伍的配套素材。每支队伍在一个文件夹内：

- `portrait.png`：选队页头像；
- `body/`：比赛球员的头部正反面、颈部、左右手臂、左右手、膝盖；
- `kits/home`、`kits/away`、`kits/goalkeeper`：主场、客场、守门员的完整球衣组件；
- `shared/generic-kit/`：守门员背面与原版回退使用的通用球衣；
- `shared/dynamic-jersey-template/`：动态队名印字所用球衣底图参考。

替换规则：保留文件名、PNG 格式、透明背景和原始画布尺寸。不要改动 `race.json` 或 `team.json`，这些文件保存了比赛骨骼和资源映射。

替换图片后，在本项目目录执行：

```bash
npm run art:apply
npm run build
```

第一条会把素材安全同步到构建源目录，并在 `美术替换备份/时间戳/` 保存替换前的版本；第二条才会重建微信小游戏分包。最后回到微信开发者工具点击“编译”。`美术整体替换包` 和备份目录已明确从微信上传包排除，不会增加包体。

当前素材仅作替换位和尺寸参考。上线前请替换成已取得商用授权或自行创作的人物、服装与头像素材。
# 美术整体替换包

本目录不进入微信小游戏上传包，只作为本地替换素材工作区。

- `teams/`：原有八支队伍的头像、身体模块和主/客/门将球衣替换包。
- `shared/`：动态球衣与通用身体模块。
- `乡村队12人/`：新的乡村足球赛单支球队完整 12 人阵容。每人一个独立目录，球衣不画进头像和头部切片，统一由动态地区队服生成。

乡村队美术放齐后执行：

```bash
npm run art:rural-apply
npm run build
```

应用过程先校验 PNG 尺寸和完整性、再自动备份运行素材；任何一个角色文件缺失都不会覆盖现有可运行资源。
