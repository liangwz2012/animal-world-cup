# 乡村观众头像母版

- 生成时间：2026-08-23
- 生成方式：Codex 内置 Image2 生图工具
- 用途：仅用于球场看台观众，不得用于主客队14名球员
- 母版：3 张 768×768 WebP，每张包含 8 名普通中国乡村群众的正面/背面配对，共 24 人
- 运行素材：由 `npm run art:rural-audience` 切片为 `crowd_01`–`crowd_24`，统一输出 81×77 RGBA PNG
- 原始高分辨率 PNG 未进入项目；压缩母版合计小于 200 KiB

人物覆盖青年、中年、老人、男女、不同脸型、发型、肤色和生活状态。提示词明确排除明星脸、时尚模特、西式脸型、重复人物及14名球员身份。生图输出的灰白棋盘背景由连通域算法移除，不按全局灰度删除，避免误伤老人白发。
