# 《乡村足球赛》3D 视觉与交互设计系统

> 方向：B——真实地域乡村环境 + 原创动画电影人物
> 目标设备：微信小游戏中档手机优先
> 状态：设计基线；实际画质需由 M1 金图和真机共同验收

## 1. 品质定义

最终画面不能是草图中的简单几何，也不能以“低多边形”作为粗糙的借口。视觉目标是：

- 第一眼能看出真实中国乡村群众足球，而不是国际通用体育场；
- 第二眼能感到人物亲切、动作有表演性、材质和光照完整；
- 放大观察能看到服装结构、脸部层次、草皮变化、看台道具和地域细节；
- 缩回比赛镜头后，球、球员、队色和操作反馈仍然清楚；
- 画质降档只减少成本，不破坏身份和玩法信息。

内部可以用“皮克斯感”帮助沟通圆润、温暖和表演性；对外设计与资产验收统一使用“原创动画电影质感”，不模仿具体影片、角色或专有造型语言。

## 2. 四个视觉支柱

### 2.1 真实生活感

球场边不是空白围栏，而是村路、田边、临时看台、小卖摊、广播桌、鼓队、摩托车停车带、儿童和返乡青年。生活元素服务于氛围，不能密集到影响比赛可读性。

### 2.2 地域可信度

地域特征以“组合证据”表达：地形 + 建材 + 植被 + 农业景观 + 色彩 + 少量符号。禁止只摆一个夸张地标或一套民族服装就声称代表整个省份。

### 2.3 人物表演性

角色面部和手脚在手机屏幕上也能读出情绪；跑动重心、停球缓冲、射门蓄力和庆祝节奏比写实肌肉模拟更重要。

### 2.4 比赛可读性

草地不能与主队球衣同色，阴影不能淹没球，观众和广告色块不能比球员更抢眼。视觉层次固定为：球和操作反馈 > 球员与队色 > 场地线 > 观众与场景。

## 3. 角色美术规范

### 3.1 比例与轮廓

- 6–6.5 头身；成年人头部略大于写实比例；
- 手掌、球鞋和小腿动作略放大，保证比赛镜头下可读；
- 肩宽、腰胯、腿长和体脂有 4–5 个基础体型，不用单一“健美运动员”模板；
- 正面、侧面和 3/4 角度都要有清楚轮廓；发型不能与头部融成无层次球体；
- 不用尖锐、廉价的低模折面表现脸和四肢，近景法线必须平顺。

### 3.2 面部

- 基础头型 6 个以上，鼻梁/鼻翼、眼型、眉形、下颌和颧骨可组合；
- 肤色覆盖自然东亚人群差异，避免用单一明暗代表地域；
- 眼睛采用克制的动画比例，不做玻璃珠式巨大反光；
- 表情形态至少包含中性、专注、用力、开心、沮丧；
- 不根据真实照片直接复刻可识别人物；合作球员另走肖像授权流程。

### 3.3 服装与球衣

- 球衣由领型、袖型、侧片、裤型、袜带、号码、短队名和地域纹样组成；
- 纹样只占可视面积 15–35%，避免把文化图案铺满全身；
- 号码和短队名在 720p 横屏比赛镜头下必须可辨；
- 主客队综合色差采用感知对比检查，颜色冲突自动切客场；
- 不使用现实国家队、职业俱乐部或村超官方标志；
- 球衣面料以粗糙度、轻法线和边缘高光表达，不做高成本布料模拟。

### 3.4 网格和贴图预算

| 项目 | LOD0 | LOD1 | LOD2 |
| --- | ---: | ---: | ---: |
| 单球员三角面 | 8,000–12,000 | 4,000–6,000 | 1,000–1,800 |
| 使用距离 | 庆祝/首页/近景 | 正常比赛 | 远端/观战 |
| 骨骼 | ≤65 | 同骨架 | 可裁减手指/面部辅助骨 |
| 单顶点骨骼影响 | ≤4 | ≤4 | ≤2–4 |
| 角色贴图 | 共享 1024 图集；英雄近景允许局部 1024 | 同图集降 MIP | 512 或共享色板 |

全队不为每个角色复制独立 1024 贴图。肤色、发色、球衣颜色和号码通过材质参数、遮罩图和小型动态纹理变化。

## 4. 动画规范

### 4.1 动作语言

- 重心先动、四肢后跟，停止时有 2–4 帧缓冲；
- 射门和长传需要清楚的预备、触球、跟随三个阶段；
- 抢断不能瞬移吸附，失败时有可读恢复；
- 庆祝动作强调普通人的喜悦和队友情感，不复制知名球星招牌动作；
- 女性、不同年龄和体型共享动作时做步幅、髋肩和速度参数校正，不简单等比缩放。

### 4.2 技术约定

- 一套共享人形骨架、统一骨骼命名、统一 A/T Pose；
- 规则位移由比赛模拟决定，动画根运动只用于视觉参考；
- 动作导出 30 FPS，压缩后保留触球关键帧；
- 左右脚动作可镜像，但脚底锁定和球触点必须重新验证；
- 使用 2D blend space 或等价状态混合处理速度与方向；
- 上半身传球/指挥可与下半身跑动叠加；
- 每次动作版本更新自动渲染正、侧、背和比赛镜头四套检查视频。

## 5. 场景美术规范

### 5.1 球场核心

- 草皮由底色、方向变化、磨损区、白线边缘和局部泥土组成；
- 禁区、门前和中圈可有轻度使用痕迹，但不能脏成专业比赛不可读；
- 球门网使用低成本网格/Shader，低档切换为简化平面或稀疏网；
- 边线外至少保留 3 米安全区，装饰碰撞不侵入操作区域；
- 计分牌、广播桌、替补席和临时围挡体现乡村赛事，不照搬职业体育场。

### 5.2 空间层级

```text
0–25 米：比赛核心、球门、替补席、第一排观众
25–60 米：看台、村路、摊位、近景建筑和树
60–128 米：田地、河流、山坡、村落剪影
128 米外：天空、雾化远山和烘焙背景层
```

只有 0–60 米使用可交互/高细节网格；远景通过简化网格、图集和大色块建立深度，禁止运行时加载实景 3D 瓦片或 3DGS 世界。

### 5.3 九个地域家族

| 家族 | 形体关键词 | 建材/色彩 | 植被与边线道具 | 禁止捷径 |
| --- | --- | --- | --- | --- |

| 北方平原麦场 | 开阔、低院墙、远地平 | 麦金、砖红、土灰 | 麦垛、防风林、农机剪影 | 全场黄沙化 |
| 东北黑土村场 | 粮仓、宽院、林带 | 深土、谷物红、木灰 | 白桦、玉米、粮仓 | 只靠冰雪代表东北 |
| 江南水乡村场 | 水网、桥、白墙屋脊 | 白、黛、稻田绿 | 河埠、小桥、竹与水生植物 | 复制旅游古镇牌坊 |

省级差异在上述家族内部通过证据化叠加完成，不破坏共享套件。

## 6. 观众设计

- 中档同屏首排 24–48 名简化 3D 观众，远排使用卡片/群组动画；
- 观众类型包括家庭、学生、老球迷、摊主、返乡青年、本地工友、女足球迷和儿童；
- 3–6 套共享身体、6–10 个头部/发型、材质色变和道具组合形成差异；
- 动画采用分组错相：挥手、鼓掌、击鼓、举旗、拍照、坐下；
- 同一排避免完全同步；低档只保留首排头肩摆动和旗帜；
- 不把少数民族服饰作为随机装扮；只有具体场景资料和审核通过时使用。

## 7. 材质与灯光

### 7.1 材质

- 场景以少量共享 PBR 材质和图集为主；
- 建筑和道具保留粗糙度层次、烘焙 AO 和轻法线，不使用纯色 Standard 作为最终近景；
- 透明材质仅用于球网、少量旗帜边缘和特效；树叶优先 Alpha Clip；
- 同家族道具使用顶点色/遮罩变化，减少材质实例和 Draw Call；
- 近景纹理像素密度统一，不能出现地面糊、建筑过锐或同一物体多种分辨率。

### 7.2 日照基线

首发只做“午后暖阳”一套确定性光照：

- 主方向光从球场斜后方 35–50° 入射；
- 天空为干净蓝青，地平线略暖；
- 静态场景使用烘焙 AO/顶点 AO，避免依赖高成本实时 GI；
- 高档：球员、球和球门投影，有限阴影距离；
- 中档：球员与球投影，观众不投影；
- 低档：接触阴影贴片/Blob Shadow，无实时阴影；
- 黄昏、雨后和夜场属于 M4 以后的独立内容，不通过简单滤镜冒充。

## 8. 镜头与构图

### 8.1 比赛镜头

- 横屏安全区域中，受控球员通常位于屏幕中心偏下 8–12%；
- 球必须在 95% 的有效比赛时间内可见；
- 摄像机兴趣点为球 65% + 受控球员 35%，长传时转向预测落点；
- FOV 38–48°，按设备宽高比微调；
- 摄像机碰撞只对近景屋檐/树冠做平滑拉近，不允许硬跳；
- 屏幕晃动只在门柱、强力射门和进球时轻量使用，并可关闭。

### 8.2 展示镜头

- 首页：球场入口或边线 3/4 机位，最多 3 名热身球员；
- 球衣预览：85 mm 等效半身/全身转台，背景中性；
- 进球：0.8 秒以内，优先展示射门者和最近队友；
- 赛果：最佳球员前景 + 主场地域轮廓，不重新加载完整场景；
- 分享卡：独立固定机位和排版模板，不依赖随机比赛截图。

## 9. 特效与音频视觉反馈

- 球的速度线只在高速射门出现，持续不超过 250 ms；
- 触球用草屑/泥点和轻音效，不使用夸张爆炸；
- 推荐传球线为半透明队色，输入结束立即淡出；
- 成功抢断用脚下短环和触觉反馈，不让全屏闪白；
- 进球可用地域色纸旗、观众动作和广播字幕，低档减少粒子数量；
- 所有粒子有最大存活数和对象池，不在比赛中动态创建大量对象。

## 10. UI 视觉系统

### 10.1 设计语言

UI 采用“乡村赛事转播 + 温暖纸牌”语言：深墨蓝信息底、米白卡片、草绿成功、朱红强调、麦金荣誉。圆角适中，不使用满屏玻璃拟态遮挡 3D 比赛。

### 10.2 核心色

| Token | 色值 | 用途 |
| --- | --- | --- |
| `ink-900` | `#15262B` | 主要文字、比分深底 |
| `paper-050` | `#FFF8E8` | 卡片和弹窗 |
| `grass-600` | `#397B4A` | 成功、主按钮、场地关联 |
| `vermilion-600` | `#C64F38` | 射门、警告、关键操作 |
| `wheat-500` | `#D1A13E` | 奖杯、排行、选中强调 |
| `sky-500` | `#4A8EAA` | 信息、下载和冷色队伍 |
| `danger-600` | `#B43A35` | 错误和不可逆提示 |

颜色不能单独传达状态；同时使用图形、文字和动画。

### 10.3 字体与文字

- 普通 UI 使用微信设备系统中文字体，避免把完整中文字库塞入主包；
- 比分数字使用可打包的精简数字字体或系统粗体；
- 自定义村名在 3D 计分牌上优先由运行时 Canvas 生成小纹理，失败时显示在 2D UI 层；
- 关键比赛字号不低于等效 24 px，辅助信息不低于 20 px；
- 一行最多显示省/市/县中的两级 + 队名，超长时优先缩短行政后缀，不做无休止滚动。

### 10.4 触控

- 关键操作视觉直径 72–84 dp，实际命中区至少 88×88 设计像素；
- 左摇杆离安全区边缘至少 24 dp；
- 右侧按键按重要性为射门 > 传球 > 冲刺/抢断 > 挑传/切换；
- 刘海、圆角和系统手势区域由安全区适配；
- 同时按下摇杆与动作键时，两个触点独立跟踪，不丢失第二触点。

## 11. 画质分档

| 项目 | 高 | 中（默认目标） | 低 |
| --- | --- | --- | --- |
| 渲染比例 | 1.5–1.75 | 1.1–1.35 | 0.8–1.0 |
| 实时阴影 | 球员/球/球门，1024 | 球员/球，512–768 | 关闭，Blob Shadow |
| 观众 | 48 近景 + 远排 | 24–36 近景 + 卡片 | 12–20 近景，静态远排 |
| 角色 LOD | LOD0/1 | LOD1 为主 | LOD1/2 |
| 远景动画 | 完整风旗/树摆 | 降频 | 静态 |
| AO/后期 | 轻 AO、色调映射 | 烘焙 AO、色调映射 | 顶点 AO、无额外后期 |
| 目标帧率 | 55–60 | 稳定 30/45 | 稳定 30 |

自动档根据启动探针、前 30 秒 GPU/CPU 帧耗和温升趋势调整；比赛中只允许逐级下降，不突然升档造成卡顿。

## 12. 金图与视觉验收

M1 必须建立以下固定金图，分辨率和相机参数版本化：

1. 球员正面全身近景；
2. 球员面部与球衣半身；
3. 主场入口看向球场；
4. 中圈比赛默认镜头；
5. 禁区射门镜头；
6. 边线观众与摊位；
7. 进球庆祝；
8. 低画质同机位；
9. 资源失败后的通用球场；
10. 主客球衣色弱模拟。

自动检查覆盖黑帧、纯色帧、相机穿模、缺失贴图、异常曝光和像素差；人工评审覆盖造型、材质、情绪、地域可信度和比赛可读性。自动通过不能替代人工签认，人工喜欢也不能覆盖真机性能失败。

## 13. 文化审核清单

每个地域家族和省级叠加必须回答：

- 哪些公开、可引用资料支持地貌、建材和植被选择；
- 哪些元素是通用套件，哪些确实具有地方性；
- 是否把一个民族、景区或城市误当成整个省；
- 是否含宗教、政治、政府机关或现实组织标志；
- 是否使用真实人物、真实队徽或受保护纹样；
- 本地审核者指出的主要误差是什么，已如何修正；
- 低画质降级后是否仍保留不冒犯、可识别的地域组合。

未经此清单审核的 AI 生成场景只能作为内部概念图，不能进入可发布资源包。
