# 《乡村足球赛》3D 版用户流程与页面说明

> 文档版本：1.0
> 日期：2026-08-02
> 适用：微信小游戏横屏体验

## 1. 页面地图

```text
启动/资源自检
  ├─ 首次地区选择
  │    └─ 球队与球衣创建
  └─ 首页
       ├─ 踢一场
       │    ├─ 快速比赛
       │    ├─ 每日挑战
       │    ├─ 乡村赛季
       │    └─ 好友约战
       ├─ 我的球队
       │    ├─ 地区与队名
       │    ├─ 球衣/队徽
       │    └─ 阵容/人物档案
       ├─ 排行与荣誉
       │    ├─ 地域榜
       │    ├─ 好友榜
       │    └─ 本地记录
       └─ 设置
            ├─ 画质/帧率
            ├─ 音效/震动
            ├─ 操作辅助
            └─ 隐私/内容说明
```

比赛流程：

```text
赛前对阵
  → 地域包检查/下载
  → 入场镜头
  → 交互教程或开球
  → 上半场式单段比赛
  → 赛果与球员表现
  → 积分/奖杯/分享
  → 再来一局或返回首页
```

## 2. 启动流程

### 2.1 正常启动

1. 立即显示轻量品牌画面和本地通用球场剪影，不等待远程资源。
2. 并行完成存档版本检查、基础资源哈希检查、设备能力识别和上次地域包索引读取。
3. 1.5 秒内给出明确状态：进入首页、恢复未完成下载或进入安全模式。
4. 首次用户进入地区选择；老用户直接进入首页。

### 2.2 安全模式

触发条件：上次运行崩溃、连续两次资源校验失败、可用内存不足或 GPU 能力不满足中画质。

安全模式自动：

- 使用本地通用球场；
- 使用基础球员和 512 贴图；
- 关闭实时阴影、AO、观众动画和高 DPR；
- 暂停后台地域包预取；
- 在设置中解释原因，并允许用户重新检测。

用户不需要理解“Shader”“WebGL”等术语。

## 3. 首次地区与球队创建

### 3.1 地区选择

步骤：

1. 省级地区卡片网格，支持拼音首字母和中文搜索；
2. 选择地级市/自治州；
3. 选择区县；
4. 选择乡镇/街道；
5. 可选填写村名、社区名或球队名；
6. 预览地域主场、球衣配色和队名完整写法；
7. 保存并进入球队创建。

规则：

- 只有省级地区是首次开局必选项，后续层级可跳过；
- 不请求 GPS 权限；
- 选择页面显示“代表地区”，不写“已定位”；
- 行政区数据缺失时允许选择上一级并继续；
- 自定义名称被拦截时保留地区选择，自动替换为“XX 乡亲队”。

### 3.2 球队与球衣

1. 系统根据地区生成 3 套安全方案；
2. 玩家选择队徽轮廓、地域纹样、主色和辅色；
3. 输入 2–4 字短队名，用于胸前和计分牌；
4. 预览主客场球衣在 3D 球员上的正面、背面和比赛远景；
5. 检查两队颜色对比度；冲突时系统自动切到客场方案；
6. 保存后进入 30 秒新手练习或跳过到首页。

## 4. 首页流程

### 4.1 信息层级

首页只保留三个主要入口：

- 主按钮“踢一场”；
- “我的球队”；
- “排行与荣誉”。

背景显示当前主场的轻量 3D 门景：球场、远山/村落、正在热身的 2–3 名球员。背景不加载完整比赛阵容，不因追求氛围增加首屏时间。

### 4.2 回访状态

- 有未完成赛季：主按钮显示“继续赛季”；
- 有好友邀请：顶部出现一张可关闭邀请卡，不强制跳转；
- 有待同步赛果：状态角标显示“1 场待同步”；
- 地域包有更新：后台下载，开始比赛前才做版本一致性检查；
- 服务离线：隐藏全球/好友实时状态，保留单机入口。

## 5. 快速比赛流程

1. 点击“踢一场”默认进入快速比赛。
2. 显示本队、推荐对手、地域、球衣和 AI 难度。
3. 玩家可换一个同级对手、切换主客场或调整难度。
4. 点击“开赛”，资源管理器判断：已缓存、需要本地分包、需要远程包或只能使用通用场。
5. 下载页面显示资源名称、大小、进度和“使用通用球场立即开赛”。
6. 资源就绪后显示 3–5 秒入场镜头，随后开球。
7. 赛后进入结果页，展示比分、关键事件、最佳球员、地域积分状态和三个动作：再来一局、分享、返回首页。

### 5.1 下载失败

- 第一次失败：自动校验 URL、缓存和哈希并重试；
- 第二次失败：不再循环，显示“地域场景暂时不可用，已切换通用球场”；
- 用户已进入比赛后，任何远程资源都不得阻塞主循环；
- 失败日志只记录匿名错误类别、资源版本和设备档位，不记录自定义村名。

## 6. 比赛内流程

### 6.1 开场

- 首局弹出四步覆盖式教程，每一步需要完成实际动作；
- 非首局只显示 3 秒操作提示；
- 开球前镜头必须停在可操作角度，不能从电影镜头突然跳变；
- 左右球衣对比不足时，在开球前自动修正客队方案。

### 6.2 控球状态

- 受控球员脚下显示队色环，持球者额外显示小三角；
- 推荐传球目标显示轻量标记，按住传球后才显示方向线；
- 射门区域用球门目标框反馈，不显示复杂数值；
- 冲刺时体力环只在低于 60% 后出现；
- 相机不能因球出界或碰撞穿入看台、树木或建筑。

### 6.3 无球状态

- 系统优先选择离球落点近、跑动方向合理的球员；
- 玩家可点“切换”手动轮换；
- 靠近持球对手时按钮切为“抢断”，远离时为“冲刺”；
- 门将自动控制，点切换不会误切门将，除非进入点球模式。

### 6.4 暂停与后台

- 单机点击暂停立即停止模拟；
- 切后台自动暂停，恢复后显示 3 秒倒计时；
- 在线房不停止服务端，宽限期由 AI 代管；
- 低内存事件发生时先降画质，若仍不足则安全返回赛前页并保存原因，不伪造赛果。

## 7. 赛后流程

### 7.1 结果页

首屏展示：

- 比分与胜负；
- 两队完整地区/队名；
- 最佳球员 3D 半身庆祝或安慰动作；
- 射门、传球成功、抢断和扑救四项核心数据；
- “本机记录”“待同步”或“已计入赛季”的明确状态。

向下展开：关键事件时间线、地域积分变化、球员成长和解锁内容。

### 7.2 分享

分享卡片使用服务器或本地模板生成，不截取可能缺素材的任意运行帧。卡片包含比分、队名、地域、经过审核的队徽和邀请动作；不包含用户 ID、精确设备信息或 GPS。

好友点击：

- 房间仍有效：登录/游客身份后进入资产检查；
- 房间已开始：可观战或创建同规则新房；
- 房间已过期：展示赛果摘要，并允许挑战同队；
- 服务不可用：进入单机“挑战这支队”的预设 AI 对局。

## 8. 赛季流程

1. 选择 4、8 或 16 队赛制；移动端默认 8 队。
2. 系统按地区邻近、实力和球衣冲突生成对手。
3. 小组/淘汰树显示下一场和已完成比分。
4. 中途退出自动保存固定步长模拟状态与事件摘要；恢复时从停表继续。
5. 赛季完成后生成奖杯、最佳射手/门将和地域荣誉卡。
6. 本地赛季不进入全球榜；接入 M5 服务后，官方赛季使用服务端赛程与签名赛果。

## 9. 排行流程

### 9.1 未接真实服务时

页面只显示：

- 本机最佳；
- 本机赛季；
- 已保存的好友挑战记录；
- “全国榜将在联网赛季开放”的真实说明。

不得填充虚构玩家和伪实时滚动数字。

### 9.2 接入真实服务后

1. 默认显示玩家代表地区的区县榜；
2. 可切换村/乡镇/市/省/全国/好友；
3. 顶部显示赛季结束时间、积分规则和同步状态；
4. 点击队伍只显示公开队名、球衣、代表地区和公开战绩；
5. 举报入口覆盖不当名称、冒充官方和不当队徽组合；
6. 被处理内容立即回退安全名称，不删除合法比赛记录。

## 10. 我的球队流程

### 10.1 修改地区

- 本地模式可随时修改；
- 联网排位每赛季只允许一次代表地区迁移；
- 修改前展示对当前榜单归属的影响；
- 历史荣誉保留原地区快照，不回写过去赛季。

### 10.2 球衣与阵容

- 球衣编辑在同一个实时 3D 模型上预览，不另做与比赛不一致的 2D 假图；
- 中文短队名自动做字体缩放和安全区域限制；
- 号码 1–99，门将默认 1 号但可调整；
- 阵容页按首发、替补和人物故事分组；
- 角色外形变化不改变竞技数值，数值来自位置职责和轻量成长。

## 11. 权限与隐私流程

首局不主动请求昵称、头像、相册、定位或麦克风。

- 微信身份：只有保存云端战绩、好友排行或创建在线房时才请求；
- 头像昵称：使用平台合规接口，拒绝后使用系统头像和“乡亲球员”；
- 相册：M1 不需要；分享使用微信标准能力；
- 定位：产品不使用；
- 麦克风：不使用；
- 删除数据：设置页提供本地清除；云服务上线后提供账号数据删除入口。

## 12. 设置与辅助

- 画质：自动、高、中、低；默认自动；
- 帧率：省电 30、流畅 45/60（设备支持时）；
- 操作：摇杆固定/跟手、按键大小、射门辅助、自动切人强度；
- 视觉：色弱友好队色、减少镜头晃动、关闭进球慢动作；
- 音频：音乐、环境、人声、震动独立；
- 字体：关键比赛信息不小于等效 24 px，按钮触控区不小于 88×88 物理像素设计值。

## 13. 关键事件埋点

只记录完成产品改进所需的事件：

- `boot_result`：档位、耗时、是否安全模式；
- `region_flow_complete`：完成到哪一级，不上报自定义村名明文；
- `asset_pack_result`：包 ID、版本、大小、耗时、结果；
- `tutorial_step`：步骤与完成/跳过；
- `match_start/end`：模式、AI 档位、时长、结果、退出原因；
- `control_error_feedback`：误触/镜头/切人反馈选项；
- `quality_switch`：原因与前后档位；
- `share_result`：入口和结果，不记录分享对象。

M0–M4 可使用本地调试日志模拟事件；只有真实分析服务接入、隐私说明更新并通过验收后，才标记为线上埋点完成。
