## 结论

当前版本可作为“本地单机候选版”继续真机测试，但还不能表述为“联网正式版已完成”。本地完整发布门禁通过；生产远程配置、排行榜和好友服务尚未部署，最新本地修改也晚于微信后台已上传的 `1.0.1`。

## 排行榜为空的直接原因

2026-08-18 只读检查结果：

- `https://coaiz.com/rural-football/config/v1`：HTTP 404；
- `https://coaiz.com/rural-rank/v1/health`：HTTP 404；
- `https://coaiz.com/rural-rank/v1/leaderboards?metric=points&scope=CN%3Aprovince`：HTTP 404；
- `npm run health:production`：失败于远程配置 HTTP 404。

客户端在远程配置不可用时按安全设计回落为：排行榜、好友对战和广告全部关闭。`src/app/main.js` 只在远程开关开启且 API 地址有效时创建可用排行榜客户端，所以当前排行榜只能显示本机统计，不会出现联网地区队数据。

此外，正式服务器数据文件尚未建立，开服地区队基础成绩也尚未写入。服务即使空部署，仍需创建基础地区榜数据或等待真实玩家完成至少 5 场合格排位后才会出现排名。

## 上线前必须完成

1. 在服务器部署排行榜、远程配置和（若首发启用）好友房间三个进程；配置真实 `WX_APP_ID`、`WX_APP_SECRET`，凭据仅存 `/etc/rural-football/rural-football.env` 且权限为 `0600`。
2. 将 Nginx 的 `/rural-football/config/v1`、`/rural-rank/v1/`、`/rural-ws` 路由接入现有 HTTPS 站点。
3. 创建排行榜持久化目录和数据文件，并实现开服地区队基础成绩；不得伪造个人微信昵称或头像。
4. 先保持远程配置三个功能关闭；服务健康、内容安全、账号删除和双真机通过后，再只开启排行榜。
5. 微信公众平台登记 `https://coaiz.com` request 合法域名；启用好友对战时登记对应 socket 合法域名。
6. 隐私保护指引如实声明微信昵称、头像、地区队和比赛统计用途；若首发不启用自拍转 Q 版，不声明或展示该能力。
7. 在 iOS、Android 各完成一整局：首页、选区、开赛、球衣地区名、音效、结算、返回；再验证主动加入排行榜、地区选择、连续 5 场、榜单刷新和账户删除。
8. 重新上传包含 2026-08-17/18 修复的版本；当前微信后台 `1.0.1` 不包含最新球衣、观众和比分栏修改。
9. 提审前保留代码及美术授权证据。自动测试不能代替微信代码相似性/权属审核。
