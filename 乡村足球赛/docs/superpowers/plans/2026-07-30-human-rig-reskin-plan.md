# 乡村足球赛人类角色骨架换皮实施计划

依据：`docs/superpowers/specs/2026-07-30-human-rig-reskin-design.md`

## 阶段 1：建立可执行骨架契约

1. 从原 `race.json` 和球队部件中提取尺寸、锚点、旋转及透明边界。
2. 生成 `rig-spec.json`，禁止人工维护重复锚点。
3. 增加契约测试，验证源素材和构建素材。
4. 修正旧 manifest 中“三分之四正面头像”的错误约束，改为严格正面和严格背面。

## 阶段 2：制作金标准人物

1. 以现有高级模型正面人物为身份参考。
2. 生成周建国统一母版：半身、严格正面头、严格后脑、统一比例。
3. 使用色键移除工具生成透明母版。
4. 从母版切出头像、正面头和背面头。
5. 使用固定蒙版派生颈、手、臂和膝，肤色及明暗来自同一母版。
6. 将角色写入新的 `rural_v2_01`，不覆盖旧 `rural_01`。

## 阶段 3：球衣与体型

1. 建立匀称、瘦高、敦实、高壮四套视觉配置。
2. 人物头部保持近似等比，躯干、肩宽、臂长和腿长分别限制。
3. 重绘一套人类球衣基础纹理并派生四套体型部件。
4. 保留地区简称、号码和主客队颜色的运行时动态绘制。

## 阶段 4：预览与运行验证

1. 增加骨架静态预览器，显示正背、左右、带球、射门和倒地姿态。
2. 运行尺寸、RGBA、透明边界、正背差异和高分辨率文件检查。
3. 构建小游戏。
4. 在微信开发工具走通首页、赛前设置、进入比赛和实际跑动。
5. 金标准通过后再切换球队第一个角色到 `rural_v2_01`。

## 阶段 5：批量扩展

1. 固化生图提示词和母版布局。
2. 按同一流程逐个生成其余 11 人。
3. 每人完成自动检查和骨架预览后才进入运行目录。
4. 完整回归后再提交和推送；不部署、不迁移数据库。
