# Image2 高清动态地名球衣实施计划

依据：`docs/superpowers/specs/2026-08-16-hires-dynamic-jersey-design.md`

## 里程碑目标

在不改变现有 Spine 骨架、附件逻辑尺寸和玩法手感的前提下，把八套程序色块球衣替换为 Image2 生成的正式乡村足球队服，并让 2–3 字动态地区简称在阵容近景和比赛近景中可靠显示。

## 阶段 1：Image2 金标准母版

1. 以现有 56×52 白色球衣轮廓作为形状参考，以现有 12 人角色图作为风格参考。
2. 使用内置 Image2 生成第一套红金正式球衣母版，要求正面、背面、专业运动面料、胸前留白、无固定文字、无号码、无商标。
3. 检查中国乡村足球气质、半写实 3D 卡通风格、领口袖口和纹样质量；不合格只做一次针对性迭代。
4. 通过后，以金标准为一致性参考生成其余七套色系。
5. 将最终母版保存到 `美术整体替换包/乡村球衣系统/image2-masters/`，保留压缩 WebP 参考，不把高清源 PNG 放入上传目录。

## 阶段 2：骨架安全切片

1. 提取 Image2 母版的布料纹样和明暗，套入现有球衣、袖子、短裤、球袜与鞋子的精确 alpha 蒙版。
2. 生成 112×104 球衣正背面；小部件保持原骨架像素，`team.json` 的逻辑尺寸、锚点、旋转保持原值。
3. 主场、客场和门将使用同一设计语言，但保持明显色差和色盲可辨识度。
4. 运行 RGBA、透明边界、尺寸、残色、同队一致性和 48 张总尺寸门禁。

## 阶段 3：动态地名可靠链路

1. 球队选择完成后预热当前比赛 12 张 112×104 动态纹理。
2. 地名只取最末级 2–3 字；完整队名保留在阵容、比分牌和场边牌。
3. 修复 Canvas 导出、动态图片注册、球队集合注入和缓存释放，输出逐阶段状态。
4. 清理残留 `__ANIMAL_*` 动态球衣内部变量，统一为 `__RURAL_DYNAMIC_*` 命名。
5. 增加真实 Canvas 及 Pixi/Spine 绑定合同测试，不能再只依赖模拟 draw-call 测试。

## 阶段 4：阵容与比赛验收

1. 阵容卡片展示动态高清球衣缩略图和完整队名。
2. 验证正面、背面、镜像、五种体型、跑动、带球、射门、倒地和庆祝。
3. 构建后生成近景与全场截图；近景读地名，全场用比分牌和场边牌稳定识别双方。
4. 运行 `npm run check`、`npm run release:check` 和包体统计。
5. 主包超过 3.4 MiB、高清球衣分包增量超过 700 KiB、总包超过 20 MiB，任一条件发生即停止交付并优化。

## 停止条件

- 本里程碑只完成 Image2 正式球衣、高清动态地名、阵容接线和相关验收。
- 不在本里程碑重做人物、骨架、球场、联网服务或部署。
- 微信真机结果由用户执行并提供，自动化和开发者工具结果不冒充真机通过。
