# 乡村足球赛：首页职业标签与队长头像云端闸门设计

> 日期：2026-08-22  
> 状态：用户已选择方案 A，等待实施计划  
> 适用版本：微信小游戏 2D 首发候选版

## 1. 目标

首页选队卡片不再用“待定”或地区简称重复占据球员标签，而是直接展示每名球员的乡村生活职业，强化“普通乡亲组成村队”的人物辨识度。

当前队长自定义只支持体型选择，与用户真正期待的自拍头像自定义不一致，因此首发先隐藏入口。项目同时增加一个专用、默认关闭的云端头像功能闸门，为后续独立开发头像上传与 Q 版生成链路保留稳定接口。

## 2. 本轮范围

### 2.1 包含

- 首页主客队 12 张首发球员卡展示 `RURAL_SQUAD.vocation`；
- 职业标签在固定卡片宽度内自动缩放，不换行、不截断为“待定”；
- 保留球员号码和现有头像方向；
- 隐藏主队第一张卡右上角“自定义”标签及点击热区；
- 保留既有体型数据、运行时缩放与本地存储兼容，不再提供首页入口；
- 增加专用远程配置 `captainAvatarCustomization`；
- 客户端实现就绪常量固定为关闭，避免云端误开形成空入口；
- 同步客户端、配置服务、示例配置与自动测试。

### 2.2 不包含

- 自拍或相册选择；
- 图片上传、抠图、Q 版生成、内容安全和人脸处理服务；
- 修改球员骨架、体型、动作、碰撞、速度或 AI；
- 删除省、市、县、乡镇之后的“自定义村名/队名”功能；该功能已有真实用途，本轮继续保留；
- 部署云端服务、申请模型 API、修改微信隐私指引或开启生产开关。

### 3.3 排版规则

- 职业标签沿用球员卡中部胶囊位置；
- 标签默认字号 12–13 px；
- 文字宽度超过胶囊安全宽度时整体等比缩小，最低字号视觉不低于 9 px；
- 标签最多展示 6 个中文字符；
- 不换行、不显示省略号、不改变球员号码位置；
- 主客队使用各自既有红/蓝色胶囊样式。

地区身份仍由面板标题、地区选择栏、比赛球衣和场边牌表达，不再在每张阵容卡重复显示。

## 4. 队长自定义入口

- 首页不绘制“自定义”角标；
- 首页不注册 `home-captain-custom` 点击热区；
- 应用层暂时保留旧动作处理与体型存储兼容，避免破坏已有本地数据和比赛运行逻辑；
- 自动测试不得再要求首页存在该入口；
- 未来头像功能完成后，可用新的头像动作替代旧体型动作，不能直接复活当前体型面板冒充头像功能。

## 5. 云端头像闸门

### 5.1 配置结构

```json
{
  "features": {
    "captainAvatarCustomization": {
      "enabled": false,
      "apiUrl": ""
    }
  }
}
```

规则：

- 包内默认值必须为 `enabled=false`；
- `apiUrl` 只接受 HTTPS，禁止本机地址、凭据和查询令牌；
- 地址为空或非法时强制关闭；
- 服务端只下发归一化字段，未知头像参数全部丢弃；
- 首发示例保持关闭和空地址。

### 5.2 双重就绪门

客户端增加不可由云端修改的包内常量：

```js
const CAPTAIN_AVATAR_CUSTOMIZATION_READY = false;
```

入口显示条件必须同时满足：

```text
包内实现就绪
AND 云端 enabled
AND 合法 HTTPS 服务地址
```

本轮包内实现未就绪，因此无论远程配置如何填写，首页都不出现头像入口，也不请求相册、相机或上传接口。

## 6. 后续头像功能边界

未来独立里程碑需要完成以下全部内容，才能把包内就绪常量改为 `true`：

- 用户主动选择自拍或相册图片；
- 明确的隐私用途、授权时机、存储期限和删除入口；
- 图片大小、格式、方向和压缩处理；
- 服务端微信内容安全及供应商安全校验；
- Q 版风格生成、失败重试和默认头像回退；
- 头像缓存、跨设备同步和账号删除；
- 模型费用、频率限制、防滥用和超时；
- 微信开发者工具与 iOS/Android 双真机验证；
- 按平台要求重新上传和审核。

云端只能在上述客户端代码已经随审核版本交付后开启功能，不能替代客户端发布。

## 7. 测试与验收

### 7.1 首页测试

- 首发阵容出现 12 个职业标签；
- 页面中不再出现球员卡“待定”；
- 主队第一张卡不再出现“自定义”角标；
- 点击原角标区域不触发 `home-captain-custom`；
- 地区级联和“自定义村名/队名”入口继续正常；
- 12 个号码、头像顺序和主客队朝向保持不变；
- 最长职业标签不越界、不换行。

### 7.2 云端配置测试

- 默认头像开关关闭；
- 非 HTTPS、带凭据、带查询令牌和本机地址强制关闭；
- 客户端与服务端归一化结果一致；
- 未知字段不进入下发结果；
- 包内就绪常量为 `false` 时，云端开启仍不显示入口。

### 7.3 发布门禁

- `npm run test:game-shell`
- `npm run test:remote-config`
- `npm run test:remote-config-service`
- `npm run release:check`

## 8. 完成与停止条件

本里程碑完成时应满足：

- 首页职业标签和隐藏入口实现完成；
- 专用云端字段完成客户端、服务端和测试同步；
- 完整发布门禁通过；
- `STATUS.md` 记录本地真实状态；
- 不实现自拍链路，不部署、不上传、不提审、不启用生产开关。
