# 首页地区选择单行布局

日期：2026-08-17  
状态：用户已通过截图和文字明确确认，进入实现

## 目标

- 左右队伍面板向屏幕边缘扩宽，中央 `VS`、球员阵容和底部操作区保持稳定。
- 省份、城市、区县、乡镇四级选择采用固定窄宽，不再平均铺满整行。
- 主队选满四级后，把“自定义村名/队名”放在四级地区右侧的同一行，不再另起一行。
- 已填写自定义名称时，同一格直接显示该名称；点击仍进入原有内容安全校验流程。
- 客队“换一个”保持在第二行，避免与主队自定义入口产生不同语义的假对称。

## 几何约束

- 设计画布仍为 `1280×720`，左右安全边距约 18 px。
- 左右面板宽度由 560 px 增至 594 px，中间保留 56 px 给 `VS`。
- 四级地区宽度依次为 88、88、92、92 px；自定义入口 158 px；间距 8 px。
- 满级主队一行总宽 550 px，完整落在面板 554 px 的内部内容区。
- 地区行仍位于原 `y=128–172`，不改变球员卡、难度、时长和开赛按钮的纵向位置。

## 验收

- 主队四级地区与自定义入口处于同一 `y` 坐标。
- 自定义入口点击仍派发 `home-region-custom`。
- 主客队地区下拉、客队换一个、12 张球员头像和底部三个入口的触控合同全部通过。
- `npm run test:game-shell`、`npm run verify` 通过。
