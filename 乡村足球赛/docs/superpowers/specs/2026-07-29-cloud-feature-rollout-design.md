# 乡村足球赛：云端能力首发关闭与后期开启设计

## 已确认目标

首发审核包默认关闭联网排行榜、好友对战和广告场次闸门，保证单机模式无限畅玩、无登录跳转、无广告和无分享解锁。后续由云端配置打开已经随首发包交付的能力，不因单纯开关变更再发布客户端版本。

排行榜必须是联网全服榜，计算积分、胜场、进球、胜率、零封和连胜；玩家只在主动加入排行榜时获取昵称和头像。好友对战必须使用真实的微信身份、邀请链接和 WSS 房间中继。真机联调由产品方完成。

## 约束与边界

- 首发包内固定一个 HTTPS 配置地址：`https://coaiz.com/animal-football/config/v1`。该域名、排行榜 HTTPS 地址及好友 WSS 地址必须在首发前登记为小游戏合法域名。
- 客户端只接受 HTTPS/WSS、白名单字段和长度受限的配置；服务不可用、配置非法或网络失败时始终回落为“全部关闭”。
- 云端开关不能替代平台审核：昵称/头像、比赛统计、广告 SDK 与其用途必须在首发时如实写入隐私保护指引；平台若自行触发复审，不能由代码绕过。
- 不在客户端或仓库保存 AppSecret、服务器密码、Token、Cookie 或广告后台凭据。
- 首发不强制分享，也不以分享作为继续游戏的唯一条件；广告功能只在已配置真实广告位且云端明确开启时显示。

## 云端配置契约

配置服务返回一个 JSON 文件，修改文件后客户端下次启动生效；缓存可在网络暂时不可用时维持上次安全配置。

```json
{
  "version": 1,
  "teams": [],
  "features": {
    "leaderboard": { "enabled": false, "apiUrl": "https://coaiz.com/animal-rank/v1" },
    "friend": { "enabled": false, "wssUrl": "wss://coaiz.com/animal-ws" },
    "monetization": {
      "enabled": false,
      "playGateEnabled": false,
      "adUnlockEnabled": false,
      "rewardedAdUnitId": ""
    }
  }
}
```

未知字段、非 HTTPS/WSS 地址、非 `adunit-` 广告位、缺失端点或版本不兼容均按关闭处理。配置只可修改已随包发布的队伍，不能下发新美术、新玩法或脚本。

## 客户端行为

1. 启动时读取缓存配置，默认值为三项能力全部关闭；后台拉取新配置不阻塞选队。
2. 排行榜开启后，公开榜可直接浏览；玩家主动点击“加入排行榜”才请求昵称、头像与微信登录，会话缓存 7 天。赛后向服务端提交全指标统计，不通过本地虚构玩家充数。
3. 好友对战开启后才展示入口；创建或进入邀请时才调用 `wx.login`，使用云端下发的 WSS 地址建立房间。
4. 广告开启后才启用场次闸门；没有真实广告位、广告加载失败或云端关闭时，直接无限畅玩，绝不退化为转发解锁。

## 服务端与运维交付

- 配置服务是只读 HTTP 服务，读取受权限保护的 JSON 配置文件并以 `no-store` 返回；它与排行榜 HTTP 服务、好友 WSS 服务分进程运行。
- 服务端保留微信 `code2Session` 校验，AppSecret 仅通过环境变量注入。
- 提供 Nginx 路由、systemd/PM2 启动示例、首发关闭配置样例、后期开启的配置样例及健康检查。
- 本轮不部署、不迁移数据库、不修改线上 Nginx；部署与真机验证后，才允许云端逐项开启。

## 验收标准

1. 无缓存、无网络或无效配置：首页不显示好友入口，排行榜标注为本机战绩，单机无限畅玩且不触发 `wx.login`、广告或分享。
2. 有效联网配置：排行榜客户端使用云端 HTTPS 地址，好友客户端使用云端 WSS 地址，广告仅在真实 `adunit-` 配置下显示。
3. 配置切换仅影响后续启动和 UI 状态；非法远端数据不打开能力、不破坏队伍、不影响开赛。
4. 本地自动测试覆盖远程配置校验、缓存/回落、功能动态刷新、广告闸门、排行榜客户端和好友服务配置；完整 `npm run check` 与 `npm run release:check` 通过。
5. 部署后由产品方真机验证：首次启动、授权后上榜、全指标赛果、好友邀请/加入/整局、广告完整观看/跳过、断网回落与横竖屏恢复。
