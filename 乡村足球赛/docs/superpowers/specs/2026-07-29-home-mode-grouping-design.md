# 首页玩法分组与赛前设置改造设计

## 目标

横版首页不再把“赛季征程、每日挑战、观看对战、排行榜、好友对战、立即开赛”并排堆在底部。玩家应一眼看清三件事：立刻踢一场、进入挑战、查看战绩或与好友玩。

## 首页布局

首页保留双方球队选择，但移除两侧阵型预览和阵型按钮。选队卡片加宽、动物头像和名称放大；不在页面顶部重复球队或 VS，只在两块选队面板的正中显示一个大号 VS。首页底部只保留一行主操作，具体玩法进入二级弹窗再选择。

1. **挑战玩法**：首页左侧次级入口。点击后打开挑战弹窗，弹窗内才显示“赛季征程”和“每日挑战”及各自进度。
2. **立即开赛**：页面唯一的金色主操作，位于中间。球队选择下方保留小号“难度：简单”和“时长：标准”标签，点击标签循环切换。
3. **战绩与好友**：首页右侧次级入口。点击后打开社交弹窗，弹窗内显示“排行榜、观看对战、邀请好友对战”。好友房未正式上线时显示一句状态说明，不留下空按钮。

首页始终只保留三个大按钮和两个小设置标签；整行按钮下移，画面只出现一个金色主按钮，避免玩家不知道先点哪里并让横版内容更饱满。

## 赛前弹窗

从“立即开赛、赛季征程、每日挑战、观看对战、好友对战”进入的比赛，均先展示同一张赛前设置弹窗。

- 弹窗只保留比赛标题和副标题，不重复显示双方球队、头像或 VS。
- 弹窗内容严格分成更大的左右两栏：左栏是主队阵型球场图与六个阵型选择；右栏是可视化操作图，不用说明段落替代手柄，直接画出更大的左手摇杆和右手的挑传、传球、射门、冲刺、铲球按钮。
- 对手阵型在左栏清晰显示，并沿用当前对局配置；本轮只让玩家在赛前调整主队阵型，避免把赛前页面重新做成复杂的双表单。
- 难度与时长不进入弹窗，继续在首页的小标签中设置并带入本场。
- 首次确认继续写入现有本地教学状态；操作区域始终保留为简明的手柄图，避免用户第二次进入又看到大段文字教学。
- 点击“开始比赛”才进入原版运行时；取消则回到首页，不消耗免费场次。
- 赛季和每日挑战在弹窗前先生成固定对手与规则；弹窗只能调整阵型，不能改变挑战对手、难度或比赛时长等锁定规则。

## 代码边界

- `src/ui/game-shell.js`：负责首页三组卡片、赛前弹窗、命中区和初次教学展示。
- `src/app/main.js`：负责把所有开赛动作统一改为“准备比赛 → 赛前弹窗 → 真正开赛”，并保留赛季/每日挑战的规则锁定。
- `tools/test-game-shell.mjs`：覆盖新卡片与赛前弹窗的点击路径。
- `tools/test-game-options.mjs`：继续验证球队、阵型、难度、时长的数据合法性。

## 验收标准

- 首页不出现阵型预览、阵型选项和大段操作教学。
- 首页只出现“挑战玩法、立即开赛、战绩与好友”三个大入口；赛季、每日、排行榜、观战和好友对战不直接堆在首页。
- 挑战与社交二级弹窗均能点通，且同类玩法归在同一弹窗。
- 首页难度与时长默认分别为“简单 / 标准”，仍可切换。
- 任意开赛路径先出现赛前弹窗；主队阵型修改能传入比赛。
- 赛前弹窗只显示直观的手柄图，不显示两行文字教学。
- 取消赛前弹窗不启动比赛，也不消耗场次。
- 好友入口关闭时布局不留空白。
