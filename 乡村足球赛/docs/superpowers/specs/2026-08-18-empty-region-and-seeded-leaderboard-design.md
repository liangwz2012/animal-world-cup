# 通用地区初始态与地区榜基础数据

## 首页地区选择

- 首次打开不预填广东、茂名、信宜或镇隆等开发者个人地区。
- 主客队均固定显示四个同排入口：`XX省 / XX市 / XX县 / XX镇`。
- 只有省级入口初始可点击；每选定一级，才解锁下一级。
- 乡镇数据继续使用 `region_data` 分包，现有完整数据量为 41,278 条；县级选定后按需加载。
- 客队“换一个”放在四级地区入口同一行最右侧，不再另起一行。

## 地区榜基础数据

- 基础数据只使用真实行政区队名，不生成个人昵称、微信头像或虚构个人档案。
- 全国省队榜、省内城市榜、市内区县榜按官方行政区数据自动生成；信宜乡镇榜首批包含镇隆、水口、丁堡、池洞、贵子、怀乡、白石、钱排。
- 每个榜单目标展示8支地区队，支持积分、胜场、进球、胜率、零封和连胜排序。
- 服务端每出现1支真实地区队，就减少1支基础队；真实地区队达到8支后基础数据完全退出。
- 客户端在生产服务尚未开启时也显示基础地区榜；联网后由服务端返回“真实队＋剩余基础队”的统一排序。

## 验收

- 默认配置的主客队地区路径和球衣地区代码为空。
- 首页能看到四级占位，锁定层级不能误触；客队换队按钮与地名同排。
- 信宜县级节点可直接加载镇隆、水口等乡镇，完整乡镇计数保持41,278。
- 地区榜初始非空；真实队伍按1:1比例逐步替代基础数据。
- 主包仍低于4 MiB，完整发布门禁通过。
