# 乡村足球赛：地区选队首页与本地文化赛场设计

日期：2026-07-30  
状态：按用户“直接开发”授权进入实现

## 1. 目标

把首页从旧的动物球队卡片，改成以真实行政区层级组织的“家乡队”选择：

- 主队按省 → 市/地州 → 区县 → 乡镇逐级选择。
- 每选完一级才出现下一级；玩家可停在任意官方层级。
- 乡镇之后允许输入村名或自定义队名；不伪造全国村级行政数据。
- 客队默认按“同级、同直接父域”自动匹配，并允许换一个或手动选择。
- 双方各展示 6 名紧凑的乡村人物半身像，仅表达“这是一支队伍”，不再选球员。
- 地区变化时首页球衣队名预览、正式比赛球衣、比分牌和场边牌同步变化，号码保持不变。
- 复用现有比赛引擎、骨架、阵型、教学、排行榜和好友房协议，不改操作手感。

## 2. 地区状态

首页配置新增独立的地区队状态，不能把完整路径塞入只允许两个代码的球衣字段：

```js
{
  path: [
    { code, parentCode, level, name, shortName },
    // province, city?, county?, town?
  ],
  customName: "",
  displayName: "镇隆",
  leafCode: "440983101000",
  leafLevel: "town"
}
```

`redTeam` / `blueTeam` 继续保留为两个不同的底层资源槽，以复用原引擎球衣、动作和碰撞逻辑；地区状态只负责身份、文字、匹配和场景。

## 3. 首页交互

横版 1280×720 页面保留底部三组入口和难度/时长设置，只替换上半部选队区域。

### 主队

1. 初始只显示“选择省份”。
2. 选省后出现“选择城市”。
3. 选市后出现“选择区县”。
4. 选区县后出现“选择乡镇”。
5. 选乡镇后出现“村名/自定义队名”。
6. 玩家在任意官方层级都可直接开赛，不强迫继续下钻。
7. 修改上级会清除后续路径和自定义名。

### 客队

- 首次选择或主队 leaf 改变时自动匹配一次，普通重绘不会反复跳动。
- “换一个”只在当前合法候选池内换。
- “手动选择”只展示当前合法候选池，不默认跨层级。
- 自定义村队仍锚定最后一个官方地区；没有真实村队池时不生成虚假村名。

### 队伍展示

- 双方各显示 6 名 192×192 半身人物的紧凑缩略图。
- 人物不可点击。
- 首页实时队名使用轻量文字叠加；正式开赛仍使用现有动态球衣 Canvas 合成。
- 12 人按地区代码稳定轮换，双方阵容顺序不完全相同。

## 4. 对手匹配

统一规则为“同级兄弟地区”：

| 主队停止层级 | 默认对手池 |
| --- | --- |
| 省 | 全国其他省级地区 |
| 市/地州 | 同省其他市/地州 |
| 区县 | 同市/地州其他区县 |
| 乡镇 | 同区县其他乡镇 |

过滤当前地区和明显不适合默认展示的泛称/纯管理区条目。候选为 1 个时直接使用；候选为 0 个时才回退上一级，并在状态中标记回退原因。

直辖市和省直管县不制造虚假的行政层：北京、天津、上海、重庆从省级直接进入区县；省直管县在省级节点下可直接进入区县。

## 5. 比赛内同步

- `redJersey` / `blueJersey` 从地区状态派生最终显示名与 leaf code。
- 比分牌、数据面板、赛果标题不再显示旧动物名，优先显示地区队名。
- 场边四块牌继续使用最细一级简称并自动缩放。
- 赛前弹窗左侧阵型保持不变；右侧标题改为“操作教学”，继续展示摇杆和动作按钮图。

## 6. 地区场景与观众

地区文化资源使用独立的主题注册表：

- 34 个省级代码都有主题元数据和安全回退。
- 首批只接入可验证的岭南主题；其他地区没有专属图时回退通用乡村球场，不阻塞开赛。
- 后续每省一张球场底图沿相同尺寸、瓦片和压缩合同加入，不把高分辨率母版直接放入运行包。
- 观众使用预生成的小图集池按比赛种子组合，不能恢复会阻塞首帧的旧 `fans.load` 动态大图集。
- 进球欢呼接现有 goal 事件；头部看球采用轻量离散方向/翻转，不参与物理和输入。

本轮交付基础设施和安全回退；完整 34 省美术属于后续批量资产生产，不伪称已经完成。

## 7. 验收

- 未选省时只出现省级入口；逐级选择后只多出现一个下一层入口。
- 任意层级可停止并开赛。
- 广东、茂名、信宜、镇隆的对手分别严格落在全国其他省、广东其他市、茂名其他区县、信宜其他乡镇。
- 北京/上海等可直接下钻区县。
- “换一个”和手动选择不越出候选池。
- 左右各恰好 6 名人物，不能点击选择球员。
- 地区变化同步首页队名，正式比赛球衣号码不变。
- 比分牌和场边牌显示地区名称。
- 赛前右栏标题为“操作教学”。
- 地区主题缺失时仍能使用通用球场开赛。
- 行政区、匹配、首页、球衣、比赛壳层、构建与原有门禁全部通过。
