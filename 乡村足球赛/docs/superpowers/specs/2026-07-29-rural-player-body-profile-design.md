# 乡村球员体型系统设计

## 目标

在不修改比赛物理、AI、碰撞、球权判定和 56 套原版 Spine 动画的前提下，让乡村球员出现可控的高矮、胖瘦和同比例大小差异。所有人物分件、球衣、号码和动作必须始终保持同一套锚点关系，不能再次依靠手工逐部位拼位置。

## 方案比较

1. 只在生图和切片阶段改变人物胖瘦：最稳，但进入同一套骨架后体型差异有限，也无法快速调试。
2. 在 `PlayerSpine` 根节点做受控 X/Y 缩放：所有骨骼、附件和动画整体一致变化，脚底支点不动，且不影响游戏实体。选择此方案作为 v1。
3. 修改每根骨骼长度和动画关键帧：自由度最高，但 56 套动画都可能产生脚漂、击球点偏移和衣服接缝，暂不采用。

## v1 体型预设

| 预设 | X | Y | 用途 |
| --- | ---: | ---: | --- |
| `balanced` | 1.00 | 1.00 | 标准体型 |
| `tall-slim` | 0.90 | 1.10 | 高瘦、敏捷 |
| `compact-strong` | 1.10 | 0.94 | 矮壮、敦实 |
| `tall-strong` | 1.04 | 1.08 | 高大、强壮 |
| `large` | 1.08 | 1.08 | 同比例偏大 |

运行时硬限制为 X/Y 均在 `0.88–1.12`，第一版不允许任意滑杆突破范围。

## 架构

- `rural-squad.js`：每名角色只声明一个体型预设名。
- `player-body-profiles.js`：保存预设、选择同队位置、查找 PlayerRenderer、应用缩放、发布诊断状态。
- `boot/start.js`：在原版 runtime 与微信适配窗口都准备完成后安装体型 Hook。
- `standalone-match.js`：每次球场名单和皮肤加载完成后调用 Hook，再进入首帧。

缩放直接设置 `PlayerSpine.scale`，以 Spine 根节点/脚底为支点。角色朝向仍由原版 `setDirection` 控制，负 X 只负责左右翻转。手持足球的容器使用反向缩放抵消人物体型，避免足球也被拉长或放大。

## 不可破坏边界

- 不修改 `player.json`、`race.json`、动画曲线和附件锚点。
- 不修改逻辑 Player 的速度、半径、位置、踢球范围、守门范围或碰撞。
- 不缩放足球、控制按钮和比赛 HUD。
- 正面和背面继续由原版 `*_back` 动画切换，不能用一张图冒充。

## 验收

1. 红蓝双方 14 个 PlayerRenderer 均获得确定性体型，同一位置跨队一致。
2. X/Y 缩放始终在安全范围，朝左时负号保留。
3. 手持足球保持原尺寸。
4. 可通过诊断接口临时把全场切到任一预设，再清除恢复角色配置。
5. 完成构建、体型单测、现有乡村名单/美术测试和全量 `npm run check`。
6. 微信开发者工具真机视觉验收仍单独记录，不把自动测试等同于真机通过。
