# 乡村足球赛：乡村荣耀榜、简化选队与地域转发设计

> 日期：2026-08-22  
> 状态：用户已确认 A「乡村荣誉殿堂」及最终精简规则，等待实施计划  
> 适用版本：微信小游戏 2D 首发候选版

## 1. 目标

把排行榜从“省队统计面板”重构为真正以村镇地域荣誉为核心的横版荣耀榜。榜单展示完整地域队名，突出乡镇、村队和家乡归属，只保留积分、进球、胜率三个容易理解的指标。

选队页与排行榜使用同一套“我的地域”层级语言，不预填开发者家乡、不显示 `XX省` 等机械占位、不使用定位权限。用户手动选择一次后静默保存在本机，下次直接恢复。

比赛和好友邀请的转发标题改为地域对阵文案，并通过专用云端白名单模板允许后续调整。

## 2. 本轮范围

### 2.1 包含

- 选队页四级入口文案和本机静默恢复；
- 横版乡村荣耀榜视觉重构；
- 全国、我的省、我的市、我的县、我的乡镇五级筛选；
- 积分榜、进球榜、胜率榜三个指标；
- 完整地域队名构建和显示；
- 全国默认跨省乡村队数据，不固定暴露广东、茂名、信宜；
- 保留数字 `1 / 2 / 3` 的金冠、银盾、铜桂冠前三名徽章；
- 比赛、好友邀请和右上角转发的地域对阵标题；
- 专用云端转发模板和严格占位符白名单；
- 客户端、服务端、种子数据、UI 和转发测试。

### 2.2 不包含

- `wx.getLocation`、`wx.getFuzzyLocation` 或任何定位权限；
- GPS、IP 定位或后台推断用户家乡；
- 新增头像、昵称或照片权限；
- 部署排行榜、配置或好友房服务；
- 数据库迁移和真实线上玩家数据操作；
- 远程脚本、任意模板表达式或未经审核的新玩法。

## 3. 选队页

### 3.1 四级入口

首次进入只显示四个同排按钮：

```text
我的省    我的市    我的县    我的乡镇
```

规则：

- 不显示“点击选择”“选择后开启”等辅助小字；
- 不显示选择示例；
- 不显示“使用上次选择的家乡队”按钮；
- 未选择上一级时，下一级保持不可点击，但视觉仍可见；
- 选中后按钮直接显示真实简称，如“广东、茂名、信宜、镇隆”；
- 用户可停在任意一级开普通单机比赛；
- 已有“自定义村名/队名”能力继续保留在乡镇选择完成后。

### 3.2 本机静默恢复

- 只保存主队家乡路径、显示名和合规自定义队名；
- 不保存定位坐标，因为本项目不获取定位；
- 每次合法选择后立即覆盖本机记录；
- 下次启动先读取并重新归一化，合法则直接恢复；
- 行政区数据版本变化导致路径失效时，回退到最后一个仍有效的层级；
- 客队不持久化，每次按主队当前层级重新生成同认知范围对手；
- 存储损坏或为空时显示四个“我的地域”入口，不预填任何真实地区。

建议存储键：

```text
rural-football:home-region:v1
```

## 4. 乡村荣耀榜信息架构

### 4.1 指标

只保留：

| 指标 | 定义 | 展示 |
| --- | --- | --- |
| 积分榜 | 有效排位胜 3、平 1、负 0 的累计积分 | 整数 |
| 进球榜 | 有效排位累计进球 | 整数 |
| 胜率榜 | 胜场 / 有效排位场次 | 一位小数百分比 |

胜场、零封、连胜、抢断、失球等数据仍可保留在内部统计和个人战报，但不再作为公开排行榜标签或主视觉指标。

### 4.2 地域筛选

榜单顶部使用一行小标签：

```text
全国    我的省    我的市    我的县    我的乡镇
```

语义：

- **全国**：全国范围内的乡镇及自定义村队，不再默认排省队；
- **我的省**：玩家所选省内的乡镇/村队；
- **我的市**：玩家所选市内的乡镇/村队；
- **我的县**：玩家所选县内的乡镇/村队；
- **我的乡镇**：同一乡镇下的合规自定义村队；没有自定义村队时显示该乡镇乡亲联队。

用户尚未选择对应层级时，该标签保持可见但不可点击，不弹定位授权。

### 4.3 榜单准入

- 普通比赛允许停在任意地域层级；
- 联网乡村榜以“选到乡镇”为推荐条件；
- 未选到乡镇的玩家仍可浏览全国和已完成层级的榜单，但提交地区队成绩前提示继续完善家乡；
- 自定义村名不是强制项；没有村名时以完整乡镇路径加“乡亲联队”参榜；
- 自定义村名必须通过既有内容安全流程。

## 5. 完整地域队名

### 5.1 数据结构

地区队记录增加只读路径快照：

```json
{
  "path": [
    { "code": "440000", "level": "province", "officialName": "广东省" },
    { "code": "440900", "level": "city", "officialName": "茂名市" },
    { "code": "440983", "level": "county", "officialName": "信宜市" },
    { "code": "440983100001", "level": "town", "officialName": "镇隆镇" }
  ],
  "customName": "天后街队",
  "fullTeamName": "广东省茂名市信宜市镇隆镇天后街队"
}
```

服务端不信任客户端直接提供的 `fullTeamName`，而是根据受支持的行政区代码和已通过内容安全的自定义名称重新生成。

### 5.2 生成规则

- 使用官方全称拼接，不使用 `XX`；
- 自定义名称已经以“队”结尾时不重复追加；
- 没有自定义名称时追加“乡亲联队”；
- 连续重复的行政区后缀不得自动删除，排行榜完整展示官方路径；
- UI 根据可用宽度缩放字号，不用省略号隐藏关键地域；极长名称允许横向紧凑字号，但保持单行；
- 网络、缓存和分享数据都保存结构化路径，不只保存展示字符串。

## 6. 默认榜单数据

用户未选择家乡时，全国榜展示跨省轮换的乡镇基础队：

- 从项目公开行政区数据中稳定取样；
- 至少覆盖五个不同省级地区；
- 不读取用户定位；
- 不固定使用广东、茂名、信宜、镇隆；
- 基础队统一命名为“完整行政路径 + 乡亲联队”；
- 不伪造头像、昵称或真实玩家身份；
- 真实乡镇/村队达到目标数量后，既有渐进替代规则继续生效。

种子只用于首屏内容完整度，不得标为“官方队伍”，也不得冒充具体真实玩家。

## 7. 视觉设计

### 7.1 整体

- 横版奶白卡片、深绿色标题和金色边框；
- 标题为“乡村足球荣耀榜”；
- 副标题为“一村一队 · 为家乡而战”；
- 指标与地域筛选使用小型胶囊标签；
- 榜单主体优先展示完整地域队名；
- 左侧个人面板缩减为头像、代表队、比赛场次和当前榜单值，不再堆叠零封、连胜等指标。

### 7.2 前三名徽章

- 第一名：以数字 `1` 为主体，外框为金色皇冠与圆形金章；
- 第二名：以数字 `2` 为主体，外框为银色盾牌；
- 第三名：以数字 `3` 为主体，外框为铜色桂冠；
- 第四名起使用普通数字；
- 皇冠、盾牌和桂冠不能替代名次数字；用户必须先看到 `1 / 2 / 3`，再感知装饰等级；
- 徽章使用 Pixi Graphics 绘制或小尺寸包内矢量等价图形，不增加高清图片和远程资源依赖；
- 金、银、铜行分别使用轻量渐变感底色，但不影响文字对比度。

## 8. 地域转发文案

### 8.1 默认文案

同一县内：

```text
茂名市信宜市乡村赛｜镇隆镇队 VS 水口镇队，快来踢球！
```

同一省不同市：

```text
广东省乡村赛｜茂名镇隆队 VS 云浮新兴队，快来踢球！
```

跨省：

```text
全国乡村赛｜广东镇隆队 VS 江西沙溪队，快来踢球！
```

规则：

- 先计算双方共同地域前缀；
- 共同前缀只出现一次；
- 队名部分优先保留双方最深层级和合规自定义村队名；
- 超过平台安全长度时按“共同赛区 → 双方最深层级 → 快来踢球”顺序保留信息；
- 比赛战报、好友邀请和右上角默认转发共用同一格式化函数。

### 8.2 云端模板

新增专用远程配置：

```json
{
  "features": {
    "regionalShare": {
      "enabled": true,
      "sameCountyTemplate": "{{commonRegion}}乡村赛｜{{redLeaf}}队 VS {{blueLeaf}}队，快来踢球！",
      "sameProvinceTemplate": "{{commonProvince}}乡村赛｜{{redCompact}} VS {{blueCompact}}，快来踢球！",
      "crossProvinceTemplate": "全国乡村赛｜{{redCompact}} VS {{blueCompact}}，快来踢球！"
    }
  }
}
```

允许占位符仅包括：

- `{{commonRegion}}`
- `{{commonProvince}}`
- `{{redLeaf}}`
- `{{blueLeaf}}`
- `{{redCompact}}`
- `{{blueCompact}}`
- `{{redFull}}`
- `{{blueFull}}`

模板规则：

- 最大 80 个字符；
- 未知占位符、HTML、换行、控制字符和脚本片段直接回退包内默认模板；
- 云端只能修改文本模板，不能下发函数、正则或脚本；
- 配置服务不可用时使用包内默认文案；
- 首发开关可以关闭，但包内格式化能力必须完整可用。

## 9. 云端排行榜接口

远程配置增加：

```json
{
  "features": {
    "ruralLeaderboard": {
      "enabled": false,
      "metrics": ["points", "goals", "winRate"],
      "scopes": ["nation", "province", "city", "county", "town"],
      "defaultScope": "nation"
    }
  }
}
```

规则：

- 包内默认关闭联网榜，单机基础榜可显示；
- 指标和范围必须经过固定枚举白名单；
- 云端可以调整默认指标、默认范围和显示顺序，但不能增加客户端未知指标；
- 排行榜 HTTP 服务继续使用已有签发比赛、防重放、限流和账户删除机制；
- 公网服务未部署前不得把联网开关设为开启。

## 10. 测试与验收

### 10.1 选队

- 首次无缓存时只显示四个“我的地域”入口；
- 页面没有 `XX省`、辅助小字、示例和“使用上次选择”按钮；
- 合法选择静默保存并在下次启动恢复；
- 损坏缓存安全回退为空；
- 不调用任何定位 API；
- 客队仍按主队层级自动生成。

### 10.2 排行榜

- 公开标签只有积分、进球、胜率；
- 地域标签为全国、我的省、我的市、我的县、我的乡镇；
- 全国默认行不是省队，而是跨省乡镇/村队；
- 每一行展示完整地域队名；
- 前三名清晰显示数字 `1 / 2 / 3`，并分别使用金冠、银盾、铜桂冠装饰；
- 切换指标和地域范围触发正确请求；
- 种子数据被真实地区队渐进替代；
- 旧零封、连胜等内部统计不丢失，但不再出现在榜单页。

### 10.3 转发

- 同县、同省和跨省三类文案正确压缩共同前缀；
- 合法云端模板生效；
- 未知占位符和超长模板回退默认；
- 好友邀请、比赛战报和右上角转发使用一致地域标题；
- 无地区数据时回退“乡村足球赛｜快来踢球！”。

### 10.4 发布门禁

- 首页、排行榜、地区、分享、配置客户端和配置服务专项测试；
- `npm run release:check`；
- 微信开发者工具横版视觉与触控验证；
- iOS、Android 真机冷启动、选队、榜单、转发和完整一局；
- 不部署、不上传、不提审、不修改真实生产数据。

## 11. 完成与停止条件

本里程碑在以下条件全部满足时结束：

- 简化选队、本机恢复、乡村荣耀榜、完整地域名称和转发模板完成；
- 客户端与服务端云端字段一致；
- 专项测试和完整发布门禁通过；
- `STATUS.md` 更新真实状态；
- 不申请定位权限；
- 不部署、不上传、不提审、不启用生产开关。
