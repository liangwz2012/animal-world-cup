# 主队红色球衣与荣耀榜地区浏览设计

## 目标

- 主队无论选择哪个地区，都稳定使用已验收的红色主场球衣；客队稳定使用蓝色球衣。地区不得随机改变双方基础色。
- 荣耀榜保留“全国 / 我的省 / 我的市 / 我的县 / 我的乡镇”五个入口。
- 第一次点击地区入口，直接查看玩家自己所在层级的榜单；再次点击当前入口，打开全国行政区级联选择器，用于查看其他同级地区。
- 浏览其他地区只改变当前榜单查询范围，不修改玩家的家乡队、球衣、参赛归属或本机持久化记录。

## 方案比较与选择

1. 严格双击计时：要求两次点击在固定毫秒内完成。PC 容易理解，但真机触摸容错差，老人和儿童不友好。
2. 当前标签再次点击（采用）：第一次切换，第二次在当前标签上点击即展开地区选择。没有时间阈值，真机行为稳定，也符合“再点一下”的操作心智。
3. 标签旁常驻下拉箭头：最显眼，但增加首页式控件噪音，不符合当前荣耀榜的简洁方向。

## 榜单显示规则

- 全国榜：显示完整地域队名，例如“贵州省贵阳市开阳县楠木渡镇乡亲联队”。
- 省内榜：标题显示完整省级名称；行内去掉共同省级前缀，突出市、县、镇差异。
- 市内榜：标题显示完整市级名称；行内去掉共同省、市前缀。
- 县内榜：标题显示完整县级名称；行内去掉共同省、市、县前缀。
- 乡镇榜：标题显示完整乡镇名称；行内只保留村队或自定义队名。
- 若无法可靠解析路径，则回退完整队名，绝不显示空白。

## 地区浏览流程

- 再次点击当前地区标签后，从省级列表开始级联选择。
- 目标是省榜时选到省即可查看；目标是市榜时继续选到市；县榜和乡镇榜同理。
- 选择器底部按钮使用“查看该地区排名”，明确这不是修改参赛地区。
- 取消或返回时恢复当前荣耀榜，不改变原查询结果。

## 数据与错误处理

- 自己的榜单范围由本地已选家乡队生成。
- 临时浏览范围仅保存在本次运行内，重新打开小程序仍默认自己的地区。
- 远程榜不可用时继续展示同范围的包内基线数据；无基线数据时显示真实空态。
- 非法地区代码、层级不匹配或地区数据加载失败时拒绝切换，并显示轻提示。

## 测试门禁

- 主队地区变化后 `redTeam` 仍为红色模板 `argentina`，客队仍为蓝色模板 `portugal`。
- 当前地区标签再次点击必须派发地区浏览动作；首次点击其他标签仍只切换范围。
- 地区浏览确认后必须使用选定同级范围键，不得调用修改玩家地区的接口。
- 省、市、县、乡镇标题使用完整官方名称；榜单行正确裁掉共同前缀。
- 完整 `npm run release:check` 通过后才允许重新上传。
