# 乡村足球赛（微信小游戏）

这是当前可运行的横版 2D 微信小游戏工程。请在微信开发者工具中直接导入本 README 所在的 `乡村足球赛` 目录，不要打开父目录或其他历史工程。

## 当前实现

- 省 / 市 / 县 / 乡镇逐级选队，并支持合规校验后的自定义队名；
- 主客队 6 人阵容、人体分层角色、动态球衣地区简称和场边队名牌；
- 横版比赛、阵型与赛前操作引导、难度和时长设置；
- 本地赛季、每日挑战、分享卡片和多指标排行榜界面；
- 排行榜服务、好友房间服务、微信身份校验、内容安全校验和账户删除代码；
- 云端开关服务。首发安全默认值关闭排行榜、好友对战和广告，配置服务不可用时仍可单机开赛。

联网代码已经在本地实现并有自动化测试，但当前仓库不代表服务已经部署、域名已经登记或双真机已经验收。开启云端开关前必须完成 `server/README.md` 中的部署和平台配置。

## 本地构建与验收

```bash
npm install
npm run build
npm run check
npm run release:check
```

- `npm run build`：从 `source-assets` 生成小游戏可上传目录；
- `npm run check`：执行构建、资源校验、功能测试和服务端合同测试；
- `npm run release:check`：追加 AppID、横屏、离线默认、旧品牌资源、角色白名单、依赖锁定和凭据扫描。

构建产物位于 `generated/`、`runtime-assets/`、`shell-assets/` 和 `region_data/`。不要手工改这些目录，应修改 `src/`、`server/` 或 `source-assets/` 后重新构建。

## 微信开发者工具

1. 导入本 README 所在目录；
2. 项目类型保持“小游戏”，方向由 `game.json` 固定为 `landscape`；
3. 普通编译验证单机流程；联网功能必须在 HTTPS/WSS 服务部署、合法域名和隐私指引完成后再开启；
4. 最终上传前运行 `npm run release:check`，并完成 iOS/Android 双真机验证。

微信后台的备案、类目、资质和隐私信息以公众平台实际审核状态为准，不在源码里重复填写或编造。昵称、头像和联网战绩的填写清单见 `docs/leaderboard-privacy-guide.md`。

## 安全与许可证

- `WX_APP_SECRET`、服务器密码、私钥和令牌只能放在服务器环境变量或密钥管理系统，不能写入客户端与仓库；
- 自定义队名的线上好友房间采用微信内容安全接口校验；未配置服务端微信凭据时，自定义名称按失败关闭处理；
- 项目受父仓库 Apache License 2.0 约束；第三方数据和素材仍须分别遵守其来源许可，行政区数据说明见 `region_data/NOTICE.md`。
