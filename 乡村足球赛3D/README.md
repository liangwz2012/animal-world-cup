# 乡村足球赛3D

面向微信小游戏全新开发的 3D 村超足球游戏。玩家从省、市、区县、村逐级选择家乡球队，在具有当地地貌、建筑、服饰和助威文化的球场中比赛，并参与地区与赛季排行。

这不是旧 2D 项目的换皮升级，而是干净隔离的新工程。旧版本只提供经过复核的需求、数值和失败经验；比赛模拟、3D 表现、资源管线、微信适配和测试体系重新建立。

## 当前阶段

当前为 M0：3D 引擎决策门。候选为 LayaAir 3.x 与 Galacean 1.x；必须用相同的最小足球切片完成微信真机对比，证据齐全后才选择正式引擎。

- 当前 Goal：docs/goals/M0-engine-decision.md
- 项目状态：docs/STATUS.md
- 验收合同：docs/ACCEPTANCE.md

## 产品底线

- 首发微信小游戏，横屏触控优先。
- 电影动画感的真实中国乡村，不接受简陋低模拼装感。
- 先做 5v5、3–5 分钟单局；足球手感优先于内容数量。
- 首个样板为贵州西南山地灵感场景，文化元素可溯源、可审核。
- 主包只留启动与首局必需资源，大资源分包/远程加载并可降级恢复。

## 目录

- assets：源资产登记与平台构建产物
- docs：产品、架构、里程碑、验收、ADR 和 Goal
- experiments：双引擎同题实验
- packages/match-core：纯 TypeScript 固定步长比赛核心
- packages/platform-wechat：微信生命周期、资源和输入适配
- packages/presentation-3d：引擎无关表现合同
- tests：跨引擎合同、回放和证据
- tools：检查、构建和测量工具

执行 npm run check 可检查当前项目骨架。
