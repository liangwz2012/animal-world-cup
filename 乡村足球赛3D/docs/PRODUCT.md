# 产品定义

## 一句话产品

《乡村足球赛3D》是一款微信小游戏上的电影动画风 3D 村超足球游戏：玩家代表自己的省、市、区县和村庄，在具有真实地域气质的乡村球场中踢出有身体感、触球感和家乡荣誉感的短局比赛。

## 核心体验

1. 选择省 → 市 → 区县 → 村，建立家乡球队身份。
2. 进入具有地方地貌、建筑、看台、饮食与助威气氛的 3D 主场。
3. 用移动、传球、射门/施压三类核心输入完成 5v5 短局。
4. 获得赛季积分和地区贡献，进入村/县/市/省多级排行。
5. 解锁经过文化审核的球衣、人物装饰和主场主题，文化表达不改变竞技数值。

## 首个可发布版本

- 一个贵州西南山地灵感的完整主场样板。
- 一套共享骨架的人类球员阵容与可换色/纹样球衣。
- 5v5、3–5 分钟、完整开球—比赛—进球—结算循环。
- 本地赛季与模拟排行；真实在线排行通过隐私和反作弊验收后再接入。
- 低/中/高三档画质和首局可玩优先的资源加载。

## 原则

- 先像足球，再像大作：响应、停球、传射方向、球速和镜头反馈优先。
- 真实气质，不是符号拼贴：地区内容使用文化证据表和本地审核。
- 动画感，不是简陋感：用轮廓、光照、材质层次和夸张但可信的动作建立品质。
- 微信优先：包体、内存、触控、前后台和弱网恢复从第一天纳入架构。

## 当前非目标

- 11v11 仿真、复杂犯规/越位、实时多人对战。
- 首版覆盖全国所有省市县村。
- 主机级写实、面捕、布料模拟和逐角色独立骨架。
- 未授权使用真实赛事名称、队徽、人物肖像、赞助商或受保护音乐。
