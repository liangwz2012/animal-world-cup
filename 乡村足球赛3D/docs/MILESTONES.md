# 里程碑

| 里程碑 | 可验证产物 | 完成后停止点 |
|---|---|---|
| M0 引擎决策门 | 同一足球切片在 LayaAir/Galacean 的 Web/微信候选；真机、包体、性能、恢复和开发体验证据；ADR-0001 | 选出唯一引擎，更新状态，不扩比赛 |
| M1-A 足球手感实验室 | 共享骨架金样、角色控制器、独立足球、传射/停球/抢断、IK/脚接触、镜头与调参板 | 手感门通过，不扩地图 |
| M1-B 贵州完整比赛 | 贵州样板主场、5v5、3–5 分钟完整局、基础 AI、结算、三档画质 | 单地区单机真机验收 |
| M2 家乡球队与内容系统 | 省市区县村选择、文化证据表、数据驱动球衣/人物/球场、第二地区 | 两个地区证明可扩展 |
| M3 赛季与排行榜 | 本地赛季、云排行、隐私、反作弊和失败降级 | 测试环境真实服务验收 |
| M4 微信发布候选 | 分包/远程资源、兼容矩阵、埋点、恢复、授权审计 | 形成可提审包，等待用户提交授权 |
| M5 灰度与复盘 | 小流量留存、性能、错误、公平性和回滚复盘 | 用户决定扩大或回滚 |

每个里程碑必须有可运行产物、自动验证、人工验收、包体/性能证据和状态更新。缺少微信开发者工具或真机证据，只能称本地实现完成。
