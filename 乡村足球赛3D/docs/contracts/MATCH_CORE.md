# MatchCore M0 合同

## 目的

MatchCore 是 LayaAir 与 Galacean 唯一允许消费的比赛事实来源。两个候选只能实现表现和平台适配，不能复制规则、修改参数或用引擎物理替代足球结果。

## 固定时间

- 模拟频率：30Hz。
- 每次 step 必须提供与当前状态一致的整数 tick；跳帧、重复或乱序立即报错。
- 渲染频率可以不同，由 PresentationFrame 在前后快照间插值。
- 数值在每 tick 末量化到 1e-5，减少长回放累计漂移。

## 坐标

- 比赛平面使用 Vec2：x 为球门方向，y 为边线方向。
- 场地 64m × 42m；主队向 +x 进攻，客队向 -x 进攻。
- 表现层映射为 3D 坐标 (x, height, z=y)，不得反向写回 MatchCore。

## 足球

- 足球拥有独立位置、速度、高度、垂直速度、占有者和最后触球者。
- 控球时使用弹簧目标形成带球，不把球挂到脚骨。
- 传球/射门释放所有权并产生 kick 事件，事件包含脚、动作类型、方向、力度和出球速度。
- 动画脚接触、IK、音效和粒子由 kick 事件驱动；表现误差不能改变进球和占有权结果。

## 确定性回放

- 基准：tests/fixtures/m0-replay.json。
- 种子：1592598566。
- 长度：240 tick。
- 当前校验值：322232d0。
- 受控摘要：tests/evidence/m0-replay-baseline.json。

两个引擎加载同一回放后必须报告上述 MatchCore 校验值；渲染帧率和设备差异不得改变它。

## 平台边界

- packages/platform-wechat 统一安全区、时间、前后台、存储和分包。
- MatchCore 不允许导入 wx、DOM、WebGL 或任何引擎 API。
- 当前自动合同已覆盖分包前两次失败、第三次成功；真实微信故障注入将在候选包中复验。
